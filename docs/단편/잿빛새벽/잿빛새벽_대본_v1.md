# 잿빛 새벽 — 전체 대본 v1

`잿빛새벽_설계_v1.md`의 퍼즐 구조(퍼즐 9개, 엔딩 3개 + 에필로그 선택)를 따르는 장면 대본. 모든 대사·전화·방송 문구의 기준 문서. 요제프 힌트 전문(11장)도 이 문서가 기준이다.

표기: [화면] · [소리] · 「독백」 플레이어 속말 · "대사" 인물 · 『자막』 화면 텍스트 · [조사] 탭 시 텍스트 · [획득] 서랍 알림 · [수첩] 수첩 자동 기록 · (전화) 상단 배너 · [방송] 수신기·스피커 음성 · [텔렉스] 텔레타이프 출력
독백은 화면 아래 띠에 한 줄씩, 탭으로 넘김. 퍼즐 조작 중에는 독백을 띄우지 않는다(오답 피드백 한 줄은 예외). 모든 음성에는 자막.

## 플레이어의 감정선 (작가 메모)

| 구간      | 플레이어가 믿는 것           | 독백의 결                                   |
| --------- | ---------------------------- | ------------------------------------------- |
| 오프닝~P3 | 렌츠 선배가 뭔가 남기고 갔다 | 신입의 긴장. 교본 문장을 속으로 외운다      |
| P4~P5     | 선배는 간첩이었다            | 배신감, 그러나 손은 멈추지 않는다           |
| P6        | 선배는 딸 때문에 묶여 있었다 | 판단을 미룬다. 짧아진다                     |
| P7        | 그레타가 협력자다            | 차갑게 식는다. 전화가 무서워진다            |
| P8        | 분소장은 선배를 버렸다       | 누구도 믿지 않는다. 혼자라는 감각           |
| P9        | 선배가 마지막으로 남긴 것    | 처음으로 선배를 이름이 아니라 아버지로 본다 |

규칙

- 플레이어는 이름·성별을 드러내지 않는다. 다들 "신입", "신입 씨", "자네"라고 부른다.
- 플레이어는 렌츠를 반전 전에는 "렌츠 선배", P6 뒤에는 "렌츠"로, P9에서 한 번 "리나 아버지"로 부른다.
- 그레타는 반전 전 대사도 다시 들으면 유도로 읽혀야 한다. 거짓말은 하지 않는다. 사실만 골라서 말한다.
- 독일어는 고유명사·코드·짧은 단어(ABBRUCH, DANKE)만. 대사는 모두 한국어.
- 이 테마는 단독 세계관. 다른 테마와 겹치는 이름·장소를 쓰지 않는다.
