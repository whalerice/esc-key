## 플레이어의 감정선 (작가 메모)

| 구간      | 플레이어가 믿는 것         | 독백의 결                  |
| --------- | -------------------------- | -------------------------- |
| 오프닝~P1 | 서명 두 번이면 끝나는 절차 | 사무적. 영감에게 조금 미안 |
| P2~P3     | 기계가 하필 오늘 고장 났다 | 당황, 기계 탓              |
| P4        | 저 안에 사람이 있다        | 처음으로 바다를 본다       |
| P5        | 내 계획서가 틀렸다         | 멈칫. 짧아진다             |
| P6        | 영감의 방식대로            | 조용히 따라 한다           |
| P7        | 사람이 보낸 불             | 단단하다                   |
| P8        | 넘겨받는다                 | 담담하다                   |

규칙

- 플레이어는 이름이 없다. 영감은 "주무관님", 선장은 "등대"나 "거기요".
- 영감은 짧게 말한다. 자기 30년을 설명하거나 자랑하지 않는다. 반전도 직접 말하지 않고, 플레이어가 일지에서 본다.
- 팔칠구는 라디오 소리로만 지나간다. 플레이어와 영감은 팔칠구에 대해 말하지 않는다.
- 늘봄시의 지명·인물은 말하지 않는다.
- "그 등대 말고"는 영감의 오래된 말버릇이다. 영감이 20년 동안 사연에 자주 쓴 이 말이 DJ 도윤에게 옮았다(해무 확정 설정). 이 테마에서도 출처를 대사로 설명하지 않는다. 물증은 P5 노란 띠지 한 장뿐.
