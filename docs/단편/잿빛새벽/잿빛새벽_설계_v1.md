> 단독 세계관 (늘봄시·해무와 연결하지 않음) · 모바일 웹 전용 · 가로 전용 + 최대 모드 · 60분 · 소리 퍼즐 포함 · 1인 플레이
> 스택: Next.js + PixiJS + Zustand + Howler + GSAP · 공통 엔진 `개발/공통엔진_v1.md`
> 다른 이름: 냉전 암호국 1983

**v2 → v3 변경 요약**

- 세로 고정 → **가로 전용 + 최대 모드**. 화면 배치와 퍼즐 레이아웃을 가로 기준으로 다시 잡았다 (8장).
- **P3 기기 회전 경로 삭제.** 가로 고정에서는 성립하지 않는다. v2.1에서 추가한 **체스판 경로를 유일한 풀이로 승격**하고, "겹치기" 버튼 대신 전문 용지를 체스판으로 끌어 놓는 조작으로 바꿨다 (P3).
- P9 오르골 곡 서술 수정: 원곡 "마지막 소절"이 아니라 **첫 줄의 끝 소절**이다. 한국에서는 '나비야'로 알려진 곡조라 원곡 소절을 알아듣기 쉽다(게임 안에서는 곡 이름을 쓰지 않는다) (P9).
- 소리 단서 재생, 다이얼·금고·모스·자판을 공통 엔진 위젯으로 옮겼다 (9장).
- 퍼즐 9개, 정답, 반전, 엔딩은 v2 그대로다.

## 1. 이야기 한 줄 요약

1983년 11월, 서베를린 지하 신호분석국 '오르겔'. 신입 해독관인 플레이어가 혼자 야간 당직을 서는 03:00. 수석 해독관 렌츠가 실종됐고, 책상엔 "핵 경보 오판 유도 작전" 전문이 남았다. 04:00 전에 취소 코드를 올바른 채널로 송신해야 한다.

**반전 2단**

- 중반(약 25분): 렌츠는 딸 리나를 볼모로 잡힌 이중간첩이었다.
- 후반(약 35분): 당직 내내 플레이어를 돕던 무전실 그레타가 진짜 내부 협력자다.
- 엔딩: 넘버 스테이션의 낭독 목소리는 리나였다.

## 4. 퍼즐 상세

### P1. 정전된 책상 (튜토리얼)

- 화면이 어둡고 손가락을 대면 빛 원이 생긴다(엔진 어둠 + 손전등 마스크). 빛 중심은 손가락보다 **화면 높이 15% 위**, 빛 반지름은 화면 높이 22%.
- 찾을 것: 포스트잇 "서랍은 시계가 멈춘 때", 탁상시계(9시 26분에 멈춤, 시침·분침 길이 차이를 크게), 3자리 서랍 자물쇠.
- 정답 926(엔진 숫자 다이얼) → 서랍에서 리나 사진(뒷면 "Lina · 7.11."), 전화번호부, 구멍 뚫린 투명 필름, 성냥갑 획득.
- 가로 화면 배치: 책상이 화면 전체 폭. 시계는 왼쪽, 서랍은 가운데 아래, 포스트잇은 오른쪽 스탠드 밑. 손전등이 화면 전체를 훑게 유도.

### P2. 닳은 다이얼

- 전화번호부: `HANS 4267`, `OTTO 6886`, `JOSEF — (번호 없음) "늘 하던 방식대로"`.
- 다이얼 구멍마다 숫자와 알파벳(2=ABC … 9=WXY). 이름 글자를 다이얼 숫자로 바꾼 규칙.
- HANS·OTTO에 걸면 짧은 응답("한스는 퇴근했어요", "오토 분소장님은 오늘 안 계십니다") → 규칙이 맞다는 확인 신호.
- JOSEF → 56733. 요제프: "렌츠 양반? 아니구먼. 그 양반이 늘 그랬지, 라디오는 사진 뒤에 적힌 그대로 맞춘다고."
- 가로 배치: 왼쪽에 다이얼 전화(지름 화면 높이 80%), 오른쪽에 전화번호부 펼침. 다이얼 위에 돌린 번호 액정, "수화기 내려놓기"로 리셋.
- 엔진 `RotaryDial`: 구멍에 손가락을 대고 멈춤쇠까지 돌려야 한 자리 입력. 멈춤쇠 전에 놓으면 무효.

### P3. 체스판 위의 전문 (v3 재설계)

- 책상 위 텔레타이프 전문 64글자. 헤더 `EMPF: ORGEL-INNEN`, 수첩에 자동 주석 "EMPF = 수신자, ORGEL-INNEN = 오르겔(우리 분소) 내부".
- 원문: `DRYTKGFNFZWKBLJVZNOVPAWVRZFWISOIJVJYWHYYJPIMPAYVIJMWKURFWYITTSWR`
- 용지는 **7열 타자 용지**로 고정 배치. 천공 줄은 6번째 열 → 세로로 읽으면 `GBVFVJVRS` (무의미). 천공은 함정이자 "어떤 열을 세로로 읽는다"는 힌트.
- 종이 모서리에 렌츠 손글씨: **"체스판처럼 읽어라"** (64글자 = 8×8).
- 렌츠 책상의 체스판: 둬 놓은 기보 종이 "… 32. … Tf8–f1" (검은 룩 f8 → f1). 체스판 위 f8에 검은 룩.
- **풀이**
  1. 전문 용지를 소지품에서 끌어 **체스판 위에 놓는다** → 64글자가 8×8 칸에 한 줄 8글자씩 깔린다(첫 줄 = 8단).
  2. 기보 마지막 수대로 검은 룩을 f8에서 f1으로 끌어내린다(또는 f1 칸 탭).
  3. 룩이 지나간 f줄 칸이 위에서부터 G · L · A · S · H · A · U · S로 켜진다 → **GLASHAUS** (작전명). 수첩 자동 기록.
- 검산: 8글자씩 끊은 각 줄의 6번째 글자 = G L A S H A U S.
- 용지를 체스판에 놓기 전 룩을 움직이면: 「판 위에 아무것도 없다.」 다른 방향으로 움직이면 룩이 제자리로.
- 해결 직후 그레타의 첫 전화 "혼자예요? 도와줄게요".
- v2 "가로 회전" 경로와 "용지를 옆으로 펼치기" 버튼은 삭제.

### P4. 넘버 스테이션

- 단파 수신기, 주파수 다이얼(회전 드래그) + 미세조정 ◀▶ 버튼. 정답 허용 범위 ±0.02 MHz, 근접 시 신호 미터 상승.
- 7.11 MHz: 오르골과 같은 멜로디(한스헨 클라인) → 여자 목소리 "페이지 열넷" → `40271 16947` 두 번 반복.
- 11.7 MHz는 잡음만(날짜 뒤집어 읽는 실수 차단).
- 수첩 숫자 키패드에 받아 적기. 왼쪽 아래 **"다시 듣기"** 버튼(그룹별). 청각 보조 모드에서는 수신기 램프 깜빡임 + 숫자 자막.
- 가로 배치: 왼쪽 수신기, 오른쪽 수첩 시트(반쯤 열림)로 들으며 적기.

### P5. 성냥갑 속 난수표 (반전 1)

- 담배를 끊은 렌츠의 성냥갑. 스와이프로 열면 난수표 책자.
- 14페이지에 투명 필름을 겹쳐 십자 표시를 맞추면(엔진 스냅 드래그, 반경 화면 기준 12px + 딸깍) 구멍으로 10자리 `4729165038`이 보인다. 필름은 모서리 홈으로 한 방향으로만 맞는다.
- 표지 규칙: "받은 숫자 − 표의 숫자, 자리마다, 받아내림 없이(음수면 +10). 두 자리씩 A=01 … Z=26."
- 40271 16947 − 47291 65038 = 03080 51919 → 03 08 05 19 19 → **CHESS**
- 자가 검증: 더하거나 거꾸로 빼면 26을 넘는 쌍이 나와 스스로 틀린 걸 안다.
- 계산은 수첩 시트에서. 수첩에 "자리 계산 칸"(10칸 × 3줄)을 제공.
- 의미: 해독관이 동측식 난수표로 지령을 받고 있었다 → 렌츠는 간첩.

### P6. 체스판 속 마이크로필름

- 체스 상자 바닥에서 필름 3컷. **필름이 거꾸로 꽂혀 있어 3컷 모두 거울상으로 시작**, 탭 한 번으로 뒤집으면 모두 바르게 읽힌다.
- 핀치 줌은 라이트박스 영역 안에서만(엔진 영역 줌, ×1~×6). 가로 화면이라 3컷이 한 줄로 나란히 놓인다. "전체 보기" 버튼.
  1. 렌츠의 고백: "6년 전부터 그들은 리나로 나를 묶었다. 이번 지령만은 따를 수 없다."
  2. 분소장이 금고 앞에 선 사진, 금고 위 메모 `R 32 · L 15 · R ??`.
  3. 메모: "그 여자의 기록은 보관소 V-17. 내 채널은 D. 요제프에게 '검은 비숍'."
- 보관소(정전, 손전등 재사용) V-17 서랍: 그레타 포겔 인사기록(출생지 공란, 추천인 불명) + 청취 일지 사본. 일지 여백에 뜨개 그림과 범례 **"1코 = · 3코 = — 안뜨기 줄 = 글자 끝"**.

### P7. 그레타의 목도리 (반전 2)

- 무전실 의자에 걸린 뜨다 만 목도리. 가로 화면에서는 목도리를 **가로로 눕혀** 보여 준다(코 묶음이 왼쪽에서 오른쪽으로). 영역 핀치 줌 ×1~×4.
- 왼쪽부터: `K K K KKK / KKK KKK KKK / KKK KKK K / K / K KKK K K / K K K KKK KKK`
- → `...- / --- / --. / . / .-.. / ...--` → **VOGEL3**
- 모스 전신기 라벨 "호출부호 입력 → 송신 기록 조회". 입력은 **[·] [—] [글자 확정] [한 글자 지우기]** 버튼(오른쪽 엄지 영역 2×2). 입력한 기호와 확정된 글자를 화면 위쪽에 즉시 표시.
- VOGEL3 입력 → "호출부호 VOGEL3: 매일 03:00, 채널 B 송신" → 그레타가 내부 협력자. 직후 무언의 전화(숨소리만, 상단 배너).

### P8. 분소장 금고

- 요제프에게 다시 전화 → 선택지 ① 렌츠 씨 어디 계세요? ② 검은 비숍 ③ 열쇠 주세요. ①·③도 각각 대답(힌트성), ②에서 "알았네, 분소장실 열쇠는 문 밑에 넣어 두지."
- 엔진 `SafeDial`: 0~39 눈금, 스티커 "R-L-R". 바깥 링을 잡으면 정밀 모드(느리게 회전), 손을 떼면 가까운 눈금에 스냅, 현재 눈금 큰 숫자 표시.
- **단계마다 맞으면 '딸깍' + 램프 점등**. 3단계는 오른쪽으로 돌릴 때 27에서만 낮은 '쿵'(청진기 바늘 게이지 동시 표시 — 소리를 못 들어도 풀 수 있음).
- 가로 배치: 금고 다이얼 왼쪽(지름 화면 높이 80%), 오른쪽에 램프 3개 + 청진기 게이지.
- 금고 안: 감찰 보고서 "렌츠가 동측에 이용당하고 있음을 확인. 역정보 통로로 계속 쓸 것. 구출하지 말 것.", 송신 형식 카드, 취소 코드 전반부 카드 "5208 — 후반부는 담당 해독관 렌츠가 보관".

### P9. 자장가의 끝 소절 + 최종 송신

- 금고를 연 뒤 정시 방송(놓치면 녹음 테이프로 재생): 렌츠의 목소리 "리나, 잠들 때까지 불러주던 노래 첫 줄 끝을 기억하니. 내가 바꾼 음만, 왼쪽부터." 이어서 허밍 `라 레 도 파 시 솔 레`(설정에서 계이름 자막 켜기 가능).
- 렌츠 책상 오르골은 노래 첫 줄의 끝 소절 `도 레 미 파 솔 솔 솔`만 연주하고 멈춘다(렌츠가 리나를 재울 때 늘 첫 줄만 불렀다는 설정).
  - 원곡은 독일 동요 '한스헨 클라인'. 한국에서는 같은 곡조의 동요로 널리 알려져 있어, 한국 플레이어는 원곡 소절을 쉽게 알아듣는다. 게임 안에서 한국 곡 이름은 쓰지 않는다.
- 오르골 실린더 핀을 드래그해 허밍과 똑같이 맞추면, **옮긴 핀 4개 아래 숫자만 빨갛게 드러남**(도=1 … 시=7). 옮기지 않은 칸에는 숫자가 없다.
- 바뀐 음: 1번째 도→라(6), 3번째 미→도(1), 5번째 솔→시(7), 7번째 솔→레(2) → **6172**
- 가로 배치: 실린더가 화면 가운데를 가로로(7칸 × 7음 높이). 핀 한 칸은 화면 기준 48px 이상.
- 송신 형식 카드: `[작전명] ABBRUCH / [취소 코드 8자리] / 내부 협력자 호출부호` + 채널 A~D 스위치.
- 정답: `GLASHAUS ABBRUCH / 52086172 / VOGEL3`, 채널 **D**.
- 송신 화면 가로 배치: 왼쪽에 텔레타이프 용지(입력 3줄) + 위쪽 채널 스위치·송신 레버, 오른쪽에 엔진 커스텀 자판(알파벳 + 숫자). 자판이 스위치·레버를 가리지 않는다.
- 금고를 연 직후 그레타 전화 "송신은 B채널이 제일 깨끗해요", 이어서 분소장 빨간 전화 "아무것도 보내지 마라".

## 5. 엔딩 (v2 유지)

- **A 「새벽은 오지 않았다」 (진엔딩)**: 채널 D + VOGEL3 기재. 경계 해제 후 수신기가 저절로 켜지고, 오르골 멜로디 뒤 여자 목소리가 "D-A-N-K-E". 국경 검문소의 두 뒷모습 사진.
- **B 「가로챈 새벽」**: 정답 코드를 채널 B로 송신. 그레타의 전화 "고마워요, 신입 씨. 이제 그 코드는 쓸 수 없어요." 렌츠 행방 불명.
- **C 「04:00」**: 시간 초과. 사이렌, 암전, 텔레타이프 한 줄 "판단 보류 — 현장 지휘관 재량."
- **에필로그 선택**: 보고서 '내부 협력자' 칸에 렌츠 이름도 적을지. 결말 문장 하나가 바뀐다.
- 코드나 호출부호가 틀리면 "인증 불일치 — 재확인하라" 회신, 게임은 계속.
- 결과 카드: 걸린 시간, 남은 시간, 힌트 수("요제프에게 3번 전화했다"), 본 엔딩 도장. 공유 이미지에 정답 코드·호출부호를 넣지 않는다.

## 6. 연출 이벤트 (진행 연동, v2 유지)

게임 시계는 03:00 → 04:00. 전화와 방송은 **퍼즐 진행에 맞춰** 울리고, 정해진 시각 이벤트는 분위기용만 둔다.

| 트리거                   | 이벤트                                                   |
| ------------------------ | -------------------------------------------------------- |
| 시작                     | 머리 위 열차, 형광등 깜빡임                              |
| P3 해결                  | 그레타 전화 "혼자예요? 도와줄게요"                       |
| P4 진입                  | 넘버 스테이션 방송 (반복)                                |
| 어떤 퍼즐에서든 5분 정체 | 요제프 순찰 전화 (체스 비유 힌트)                        |
| P7 해결                  | 무언의 전화                                              |
| P8 해결                  | 렌츠 목소리 방송 → 그레타 "B채널" → 분소장 "보내지 마라" |
| 매 15분                  | 괘종, 텔레타이프 경계 단계 자동 갱신                     |

조작 중에는 전화가 퍼즐 화면을 덮지 않고 상단 배너로 울린다(엔진 배너 계층).

## 7. 힌트 체계 (v2 유지)

- 경비실(요제프)에 전화 = 힌트(엔진 힌트 채널 스킨 "경비실 전화"). 퍼즐별 3단계(방향 → 구체 단서 → 정답), 체스 비유 어투.
- 같은 퍼즐 5분 이상 정체 시 전화기가 은은하게 깜빡임.
- 힌트 단계 열기는 길게 누르기.
- P3 힌트는 체스판 경로 기준으로 교체: "렌츠 양반은 종이도 판 위에서 읽었지." / "그 전문, 체스판에 깔아 보게. 한 칸에 한 글자." / "마지막 수대로 검은 룩을 f줄로 내리게. 지나간 칸이 답이야."

## 8. 모바일 화면 (가로 전용 + 최대 모드)

공통 엔진 화면 틀을 따른다. 이 테마만의 것만 적는다.

| 영역             | 내용                                                                          |
| ---------------- | ----------------------------------------------------------------------------- |
| 왼쪽 위          | 벽시계 (03:00 → 04:00, 남은 분)                                               |
| 왼쪽 가운데      | 뒤로                                                                          |
| 왼쪽 아래 엄지   | **다시 듣기** (소리 단서가 있는 화면에서만: P4, P9 허밍·방송, 전화 다시 듣기) |
| 오른쪽 위        | 수첩, 음소거, 설정, 최대 모드                                                 |
| 오른쪽 세로      | 소지품 서랍 (칸 5개)                                                          |
| 오른쪽 아래 엄지 | 경비실 전화 (힌트)                                                            |

- **시작 게이트**: "이어폰을 끼고 시작". 모바일은 화면을 크게 볼지 물은 뒤, 동의한 탭에서만 최대 모드. PC는 펼치지 않고 HUD 「최대」 버튼만. 이어서 오디오 + 화면 꺼짐 방지. 무음 스위치 안내 한 줄("소리 단서가 있어요. 무음이어도 들리게 재생하지만, 볼륨을 올려 주세요").
- 수첩: 얻은 답을 획득 소품 아이콘과 함께 자동 기록 + 숫자 키패드 메모 + P5 자리 계산 칸. 퍼즐 위에 **화면 오른쪽 절반 시트**로 열어 동시에 보기.
- 방 이동은 핫스팟 탭 → 확대(최대 2단계), "뒤로". 좌우 스와이프 이동 금지.
- 설정(엔진 공통 + 이 테마): 어둠 보정, 청각 보조 모드(소리 단서의 시각 대체), 계이름 자막, 한 손 모드(핀치 대신 ± 버튼), 글자 크게.
- 이 테마는 기기 회전을 쓰지 않는다. 세로로 들면 엔진 공통 회전 안내 + 일시정지.

## 9. 구현 메모 (공통 엔진 기준)

### 9-1. 테마 정의

```ts
world: 'standalone'
lengthMin: 60
gate:  { label: '이어폰을 끼고 시작', needs: [] }
timer: { skin: 'wall-clock', durationMs: 60 * 60_000, onZero: 'C' }   // 03:00 → 04:00
hud:   { inventoryName: '소지품 서랍', hintChannel: 'guard-phone', notebook: true }
extra: { radioFreq: 0, lockStage: 0, morseInput: '', cylinderPins: [], sent: null, epilogueChoice: null }
```

### 9-2. 소리 단서

- 넘버 스테이션(P4), 렌츠 방송·허밍(P9), 금고 '쿵'(P8)은 소리 단서. iPhone 무음 스위치에 묻히지 않게 HTML5 오디오 방식으로 재생하고, 지원하는 Safari에서는 오디오 세션을 재생용으로 둔다.
- 모든 소리 단서에 시각 대체: P4 숫자 자막 + 램프, P8 청진기 게이지, P9 계이름 자막.
- 주파수 다이얼: 정답 주파수와의 거리로 잡음·신호 볼륨을 섞는다(Howler 두 트랙 크로스페이드). 허용 범위 ±0.02 MHz 안에서만 숫자 낭독 트랙.
- 전화 음성이 나오면 배경 덕킹 40%.

### 9-3. P3 체스판

- 소지품의 전문 용지를 체스판 영역에 놓으면(엔진 `onUse`) 64글자를 8×8 칸에 깐다. 첫 줄 8글자 = 8단(a8~h8).
- 검은 룩은 f8에서 f줄 아래 방향으로만 드래그 가능, 놓은 칸까지 지나간 칸을 켠다. f1까지 가면 해결. 중간에 놓으면 켜진 글자까지만 보이고 룩은 제자리로.
- 7열 용지 화면의 천공 줄(6번째 열)은 그림으로 고정 배치(기기 폭과 무관).

### 9-4. 위젯

- P1·보관소: 엔진 어둠 + 손전등 마스크.
- P2: `RotaryDial`, P8: `SafeDial`(정밀 링, 스냅, 단계 램프).
- P5: 스냅 드래그(필름), 홈 방향 체크.
- P6·P7: 엔진 영역 줌(라이트박스, 목도리).
- P7: 모스 버튼 4개는 DOM 버튼(누르는 시간 판정 없음).
- P9: 오르골 실린더 7칸 × 7음 격자 드래그, 옮긴 핀만 숫자 표시. 송신 화면 자판은 엔진 `Keypad` 커스텀(A~Z, 0~9, 공백, 지우기).

### 9-5. 저장

- 저장 키 `escape:ashen-dawn`. 60분 테마라 중간 이탈이 많다 → 퍼즐 해결·아이템 획득·전화 이벤트마다 저장, 이어 하기 시 마지막 장면과 남은 시간 복원.

## 10. 예비 퍼즐 뱅크 (교체·확장용)

대출 카드 연필 탁본(v1 P7), 시저 암호 원판(두 손가락 회전), 릴 테이프 역재생, 상황판 선 긋기(숫자 모양), 파쇄 문서 복원, 내부자 논리 퍼즐(교대표·꽁초·립스틱), 필름 3장 겹치기 메타, 순찰 발소리 숨기.

## 11. 남은 검증 항목

- P3: "체스판처럼 읽어라" 단서만으로 용지를 체스판에 올려 볼 생각을 하는지 (회전 경로가 없어진 만큼 중요)
- P3: 7열 용지의 천공 줄이 지나친 헛수고를 만들지 않는지
- P9: 계이름 자막 없이 허밍만으로 풀 수 있는 비율 (원곡에 익숙한 한국 플레이어 기준으로 다시 측정)
- 무음 스위치 켠 iPhone에서 소리 단서가 들리는지
- 가로 화면에서 목도리 코 묶음 간격이 구분되는지
- 전체 플레이 시간 실측 (목표 55~60분)
