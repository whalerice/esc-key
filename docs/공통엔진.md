# 공통 엔진 v1 — 모바일 웹 방탈출 (Next.js + PixiJS)

> 대상: 늘봄시 4테마(1/12 · 겨울 온실 · 붉은 방 · 막차 이후)부터 적용. 해무·잿빛 새벽도 같은 엔진을 쓴다.
> 스택: Next.js + PixiJS + Zustand + Howler + GSAP
> 대체 문서: `개발/Unity_웹템플릿_EscapeMobile.md` (폐기)

## 0. 한 줄 요약

모든 테마는 **같은 시작 게이트, 같은 화면 틀, 같은 입력·줌·부품함·힌트·저장**을 쓰고, 테마는 장면·퍼즐·대사·연출 데이터만 만든다. 테마마다 다른 것은 "남은 시간 표시 모양"과 "힌트를 주는 사람" 정도다.

---

## 1. 기본 원칙

| 항목 | 기준 |
|---|---|
| 기기 | 모바일 웹 전용, 터치 조작만. PC는 개발 확인용으로만 띄운다 |
| 방향 | 가로 전용. 세로면 안내 화면 + 일시정지 |
| 최대 모드 | 시작 게이트 탭에서 전체화면(주소창 숨김) 진입. 안 되는 기기는 홈 화면 추가로 대체 |
| 길이 | 30분 테마(늘봄시·해무), 60분 테마(잿빛 새벽) |
| 소리 | 시작 게이트 탭 전에는 소리 없음. 소리 단서가 있으면 반드시 시각 대체 |
| 저장 | 퍼즐 하나 풀 때마다 자동 저장. 탭을 닫아도 이어 하기 |
| 실패 | 테마가 정한다. 엔진은 "시간 초과 엔딩 있음/없음" 둘 다 지원 |

## 2. 도구별 역할

| 도구 | 맡는 일 | 맡지 않는 일 |
|---|---|---|
| Next.js | 라우팅(허브, 테마 페이지), DOM 화면(시작 게이트, HUD, 대사·편지 카드, 수첩, 설정, 결과 카드), 정적 내보내기 | 게임 장면 그리기 |
| PixiJS | 장면, 핫스팟, 줌 카메라, 퍼즐 조작(다이얼·드래그·자석·필름 등), 화면 필터, 마스크 | 글씨가 많은 화면 |
| Zustand | 공통 설정, 테마별 진행·부품함·수첩·힌트·타이머, 로컬 저장 | 장면 안 오브젝트 위치 같은 순간 상태 |
| Howler | 배경 루프, 효과음 스프라이트, 소리 단서, 전화·무전 음성 | 마이크 입력 |
| GSAP | 열림·켜짐·관성·카메라 이동·엔딩 연출, 타임라인 | 게임 시간 계산 |

**글씨 원칙**: 문장이 두 줄 이상이면 DOM, 장면 안 소품 글씨(봉투 주소, 달력 메모)는 그림으로 굽는다. 한글이 선명하고 "글자 크게" 설정이 쉽다.

## 4. 화면 계층

위에서 아래 순서. 위 계층이 터치를 먼저 받는다.

| 순서 | 계층 | 그리는 곳 | 내용 |
|---|---|---|---|
| 1 | 시스템 오버레이 | DOM | 세로 안내, 시작 게이트, 오류 |
| 2 | 모달 | DOM | 편지·쪽지 카드, 수첩, 설정, 결과 카드 |
| 3 | 배너 | DOM | 전화·무전 수신 배너(퍼즐을 덮지 않는 상단 띠) |
| 4 | HUD | DOM | 남은 시간 표시, 뒤로, 힌트, 부품함, 음소거, 최대 모드 |
| 5 | 내레이션 띠 | DOM | 화면 아래 22%, 한 줄씩 탭으로 넘김 |
| 6 | 화면 필터 | PixiJS | 안전등, 어둠·손전등, 성에 |
| 7 | 퍼즐 패널 | PixiJS | 다이얼·자물쇠 확대 패널(배경 줌 고정) |
| 8 | 장면 | PixiJS | 공방·암실·온실·분실물 센터 |

- 모달이 열리면 PixiJS 입력을 잠그고, 장면 시간은 흐르게 둔다(연출 타이머 유지).
- 시스템 오버레이가 뜨면 게임 시간까지 멈춘다(9장 일시정지).

## 5. 시작 게이트와 최대 모드

### 5-1. 흐름
```
테마 페이지 열림 → 그림·소리 불러오기(진행 바)
→ 시작 게이트 (테마별 문구: '공방 문 열기', '암실에 들어가기', '문 열기' …)
→ [한 번의 탭 안에서] 전체화면 → 가로 고정 → 오디오 깨우기 → 화면 꺼짐 방지 → (필요한 테마만) 마이크 / 기울기 권한
→ 오프닝
```
브라우저는 전체화면·소리·권한을 **사용자 탭 안에서만** 허락하므로, 이 순서를 한 탭 핸들러 안에서 동기적으로 시작한다. 권한 요청 결과는 기다리지 않고 게임을 시작하고, 결과가 오면 대체 경로를 고른다.

### 5-2. 기기별 처리

| 환경 | 최대 모드 | 가로 고정 | 비고 |
|---|---|---|---|
| Android Chrome·삼성 인터넷 | 전체화면 진입 | 전체화면 상태에서 가로 고정 시도 | 뒤로가기로 풀리면 HUD 최대 모드 버튼 깜빡임 |
| iPhone Safari | 페이지 요소 전체화면 미지원 | 고정 불가 | 홈 화면 추가 안내(처음 한 번), Safari 안에서는 `100dvh`로 화면 높이 맞춤 |
| iPhone 홈 화면 실행 | 주소창 없이 실행(웹 앱 설정) | 고정 불가 | 세로 안내 화면으로 대응 |
| iPad | 전체화면 진입 | 고정 불가 | 화면이 커서 배치만 확인 |

- 웹 앱 설정(`manifest`): 표시 방식 전체화면, 방향 가로, 배경색 검정. iOS용 웹 앱 메타 태그도 함께 둔다.
- 전체화면이 풀려도 게임은 멈추지 않는다. 최대 모드 버튼만 깜빡인다.
- "홈 화면 추가" 안내는 테마별이 아니라 앱 전체에서 한 번만 띄우고, 다시 보지 않기를 저장한다.

### 5-3. 세로 안내와 예외
- 세로로 들면 회전 안내 + 일시정지. 가로로 돌아오면 그 자리에서 재개.
- **예외: 엎어두기(붉은 방)** 중에는 기기가 뒤집히면서 방향 이벤트가 튈 수 있다. 엎어두기 상태에서는 회전 안내와 일시정지를 끈다(`orientation.suppress()`).

## 6. 좌표계와 해상도

- 논리 화면 **1920 × 1080**. 실제 화면에 비율을 유지한 채 맞추고(contain), 남는 띠는 장면 배경색으로 채운다.
- 가로 최대 모드 실제 높이는 기기에 따라 약 360~430 CSS px. **높이 360px 기준으로 터치 크기를 정한다.**
- 화면 배율(DPR) 상한 2. 저사양 판정 시 1.5.
- 노치·홈 바 영역(safe area) 값을 CSS 변수로 받아 HUD를 그 안쪽에 둔다. 장면 그림은 safe area 밖까지 깔아도 된다.
- 조작 금지 띠: 좌우 끝 24px, 아래 끝 20px(시스템 제스처 충돌). 이 안에는 단서도 두지 않는다.

## 7. 입력

### 7-1. 기본 설정
- 게임 영역 `touch-action: none`, 문서 `overscroll-behavior: none`, `user-select: none`, `-webkit-touch-callout: none`.
- iOS 확대 막기: viewport `user-scalable=no` + `gesturestart`/`gesturechange` 기본 동작 막기.
- 모든 입력은 Pointer 이벤트로 받는다. 손가락 여러 개는 pointerId로 구분.

### 7-2. 제스처 (`engine/input/gestures.ts`)

| 제스처 | 판정 | 쓰는 곳 |
|---|---|---|
| 탭 | 10px 이내 이동, 300ms 이내 | 핫스팟, 자석, 찾기 |
| 더블 탭 | 탭 두 번 280ms 이내 | 줌 한 단계 (한 손 모드) |
| 길게 누르기 | 600ms 유지 (값 조절 가능) | 힌트 단계 열기, 입김 대체, 되돌릴 수 없는 선택 확정 |
| 드래그 | 10px 넘게 이동 | 손전등, 필름, 사진, 줄자, 플러그 |
| 스냅 드래그 | 놓을 때 목표 반경 안이면 붙음 | 필름 겹치기, 줄자, 사진 걸기 |
| 회전 드래그 | 중심점 기준 각도 변화 | 다이얼 전화, 금고, 크랭크, 온도 다이얼 |
| 핀치 | 두 손가락 거리 변화 | 줌 카메라 |

### 7-3. 탭 영역
- 화면 기준 최소 44 × 44px. 그림이 작아도 탭 영역은 줄이지 않는다.
- 줌 중인 장면에서는 탭 영역 반지름 = 22px ÷ 현재 배율 (1/12 방식).
- 겹치면 "반응 최소 배율"이 높은 쪽, 그다음 화면에서 위에 있는 쪽이 우선.

## 8. 공통 위젯과 시스템

### 8-1. 줌 카메라 (`ZoomCamera`)
- 핀치 줌, 한 손가락 이동, 더블 탭, ± 버튼(한 손 모드).
- 설정값: 최소·최대 배율, 문턱 배율 목록(문턱 근처 끌림), 이동 범위(잠긴 영역 제외), 관성 길이.
- 문턱을 넘으면 이벤트를 낸다 → LOD 교체, 숨은 조각 탭 허용, 효과음.
- 장면 전체 줌(1/12)과 영역 안 줌(잿빛 새벽 라이트박스, 막차 스티커 사진) 둘 다 같은 위젯. 영역 안 줌은 사각형 마스크로 범위를 제한한다.

### 8-2. 다이얼·키패드

| 위젯 | 설명 | 쓰는 테마 |
|---|---|---|
| NumberDial | 칸을 위아래 드래그, 칸마다 딸깍 | 1/12, 붉은 방, 겨울 온실 |
| LetterDial | 칸마다 음절·알파벳 후보 | 1/12 |
| RotaryDial | 원형 다이얼 전화(구멍에 손가락, 멈춤쇠까지) | 붉은 방(최 영감), 잿빛 새벽 |
| SafeDial | 0~39 눈금, 정밀 모드, 단계 딸깍·램프 | 잿빛 새벽 |
| Keypad (DOM) | 숫자 / 알파벳 / 천지인 / 커스텀 자판 | 막차 이후(천지인), 겨울 온실(알파벳), 잿빛 새벽(텔레타이프) |

- 다이얼·자물쇠는 **퍼즐 패널**(4장 7번 계층)로 띄워 배경 줌을 고정한다.
- 정답 판정은 위젯이 아니라 퍼즐 코드가 한다. 위젯은 값 변화 이벤트만 낸다.
- 오답 피드백 공통: 흔들림(GSAP 0.3초) + 효과음. 페널티(시간 감소 등)는 테마가 정한다.

### 8-3. 부품함 (`Inventory`)
- 화면 오른쪽 세로 칸 5개, 넘치면 스크롤. 테마가 이름과 그림만 바꾼다(부품함, 소지품, 서랍).
- 칸 탭 → 가운데 확대 뷰어(핀치 줌, 탭으로 뒤집기).
- 칸에서 장면으로 끌어 쓰기(사용 대상 위에서 놓으면 `onUse(itemId, targetId)`).
- 획득 연출: 장면에서 칸으로 날아가는 GSAP 곡선 + 바스락.

### 8-4. 수첩 (`Notebook`, DOM)
- 얻은 숫자·단어·메모를 소품 아이콘과 함께 자동 기록. 숫자 메모 입력 칸.
- 열면 화면 오른쪽 절반 시트로 열려 왼쪽 퍼즐과 나란히 본다(겨울 온실 P5·P6, 잿빛 새벽).
- 1/12처럼 수첩이 없는 테마는 끈다.

### 8-5. 힌트 (`Hints`)
- 퍼즐마다 3단계(방향 → 구체 단서 → 정답), 단계 열기는 길게 누르기.
- 힌트 채널 모양은 테마가 정한다: 다이얼 전화(붉은 방), 무전기(겨울 온실), 내선 전화(막차 이후), 작가의 메모장(1/12), 경비실 전화(잿빛 새벽).
- 첫 연락 때 한 줄 이야기(최 영감 옛이야기, 남 씨 커피 이야기)를 붙이는 기능: `hint.intro[puzzleId]`.
- 정체 감지: 같은 퍼즐 N분(테마별 3~5분) 진행 없으면 힌트 아이콘 깜빡임.
- 힌트 사용 수는 결과 카드에 표시.

### 8-6. 남은 시간 (`Timer`)
- 하나의 시계, 표시 모양만 테마별 스킨.

| 스킨 | 테마 | 0이 되면 |
|---|---|---|
| 없음 (걸린 시간만 기록) | 1/12 | — |
| 온도계 14°C → 0°C | 겨울 온실 | 엔딩 B |
| 기계식 암실 타이머 30분 | 붉은 방 | 엔딩 C |
| 폰 배터리 | 막차 이후 | 엔딩 B |
| 벽시계 03:00 → 04:00 | 잿빛 새벽 | 엔딩 C |

- 남은 시간은 실제 시각 기준으로 계산하고, **일시정지 구간(세로, 백그라운드, 시스템 오버레이)은 빼서** 공정하게 한다.
- 시간 보정 기능: 멈춤(겨울 온실 온풍기 3분), 감소(붉은 방 −1분, 막차 −20초). 테마가 `timer.pause(ms)`, `timer.penalty(ms)` 호출.
- 경보 지점 이벤트(10분·5분 남음, 7°C·3°C)를 테마에 알려 연출을 건다.

### 8-7. 진행 이벤트 (`Events`)
- "퍼즐 해결", "장면 진입", "정체 N분", "타이머 지점", "아이템 획득"에 연출을 묶는 표. 테마 데이터로 선언한다.
```ts
events: [
  { on: { solved: 'P3' }, run: ['call:greta-first', 'banner'] },
  { on: { stalledMin: 5 }, run: ['hint:blink'] },
  { on: { timerLeftMin: 10 }, run: ['fx:tick-louder'] },
]
```
- 전화·무전은 조작 중이면 상단 배너로만, 퍼즐 화면을 덮지 않는다.

### 8-8. 화면 필터와 마스크 (`fx`)

| 기능 | 방법 | 쓰는 곳 |
|---|---|---|
| 안전등 | 장면 전체에 붉은 채널만 남기는 색 행렬 필터. 빨간 잉크와 종이가 같은 밝기가 되어 사라지고 파란·검은 글씨만 남는다 | 붉은 방 P1·P7 |
| 어둠 + 손전등 | 검은 레이어에 손가락 위치 원형 구멍(손가락보다 위쪽, 화면 높이 15%) | 잿빛 새벽 P1, 보관소 |
| 완전 암흑 | 검은 레이어 + 야광 점만 그리기 | 붉은 방 P2 |
| 성에 | 가장자리부터 번지는 텍스처, 중앙 80%는 반투명 상한 | 겨울 온실 |
| 누적 마스크 | 손가락이 머문 영역을 텍스처에 쌓아 비율 계산 | 붉은 방 닷징 P8 |
| 뷰파인더 | 사각 영역 안에만 다른 장면(2009년) 그리기 | 막차 이후 P4·P5 |

- 안전등은 화면 색 보정(야간 모드, 블루라이트 필터)과 상관없이 같은 결과가 나오게 **그림 단계에서** 계산한다. 그림을 그릴 때 빨간 잉크의 붉은 채널 값을 종이와 같게 맞춘다.

### 8-9. 엔딩과 결과 카드
- 엔딩 정의: 조건, 연출 장면 목록, 타이틀.
- 결과 카드(DOM + PixiJS 이미지): 걸린 시간, 힌트 수, 본 엔딩 도장, 테마별 추가 항목(기억 조각 n/8, 이름표 여덟 장).
- 공유 이미지는 스포일러 제외 규칙을 테마가 정한다.

## 10. 센서와 권한

### 10-1. 입김 (`BreathDetector`, 겨울 온실)
- 마이크 → 소리 분석기. '후—'처럼 넓은 대역 잡음 크기가 기준 이상으로 1.5초 쌓이면 성공.
- 판정은 해당 장면(유리 확대 화면)에서만 켜고, 끝나면 마이크 트랙을 바로 끈다(마이크 표시등 끄기).
- iPhone은 마이크를 켜는 동안 소리 출력이 작아지거나 경로가 바뀔 수 있다. 마이크를 끈 뒤 오디오를 다시 깨운다.
- 대체: 권한 거부·마이크 없음·3회 실패 → 길게 누르기 1.5초.

### 10-2. 엎어두기 (`FaceDownDetector`, 붉은 방)
- 기기 방향 값으로 화면이 위를 보는 정도 = cos(beta) × cos(gamma). 이 값이 −0.8 이하로 1초 유지되면 엎은 것으로 본다. 가로·세로 어느 방향으로 뒤집어도 같은 식으로 판정된다.
- iOS는 시작 게이트 탭 안에서 방향 센서 권한을 요청한다.
- 대체: 권한 거부·센서 없음 → "엎어두기" 버튼. 화면이 까매지고 정해진 시간 동안 터치하지 않아야 한다.
- 엎어둔 동안 회전 안내 끔(5-3), 화면 꺼짐 방지 유지.

### 10-3. 공통
- 진동은 연출에도 쓰지 않는다(iPhone 미지원, 경험 차이).
- 권한은 시작 게이트에서 한 번에, 필요한 테마만. 거부해도 게임은 반드시 끝까지 갈 수 있어야 한다.

## 11. 사운드 (`SoundManager`, Howler)

- 시작 게이트 탭에서 오디오를 깨운다. 그 전에 소리를 내려는 호출은 대기열에 두지 않고 버린다.
- 테마마다 효과음 스프라이트 한 파일 + 배경 루프 1~2개.
- **소리 단서**(넘버 스테이션, 자장가, 전화 음성)는 iPhone 무음 스위치에 묻히지 않게 HTML5 오디오 방식으로 재생한다. 지원하는 Safari에서는 오디오 세션을 재생용으로 설정한다.
- 모든 소리 단서에 시각 대체(자막, 램프 깜빡임)를 둔다. 설정 "청각 보조 모드".
- 덕킹: 전화·무전 음성이 나오면 배경을 40%로 낮춘다.
- 볼륨은 배경·효과음·음성 세 갈래. 음소거 토글은 HUD 오른쪽 위.

## 12. 상태와 저장 (Zustand)

### 12-1. 앱 공통 저장소 (`appStore`)

type AppSave = {

### 12-2. 테마 저장소 (`createThemeStore`)
```ts
type ThemeSave<TExtra> = {
  version: number;
  scene: SceneId;
  solved: Record<PuzzleId, boolean>;
  items: ItemId[];
  notebook: NoteEntry[];
  hintsUsed: Record<PuzzleId, 0 | 1 | 2 | 3>;
  timer: { elapsedMs: number; bonusPausedMs: number; penaltyMs: number };
  flags: Record<string, boolean>;   // 이벤트 1회성 기록
  extra: TExtra;                    // 테마 전용(기억 조각, 개화 단계, 이름표 글씨 등)
};
```
- 저장 키 `escape:<themeId>`. 퍼즐 해결, 아이템 획득, 백그라운드 진입 때 저장.
- 버전이 다르면 테마의 `migrate`로 옮긴다. 실패하면 "처음부터 하기"만 제안.
- 저장소는 페이지 밖에서도 읽을 수 있게 해서, 늘봄시 목록 화면에 "이어 하기 · 진행 3/8"을 보여 준다.

## 13. 테마 정의 (`ThemeDefinition`)

```ts
type ThemeDefinition = {
  id: ThemeId;                       // 'neulbom-112'
  world: 'neulbom' | 'haemu' | 'standalone';
  title: string;
  lengthMin: 30 | 60;
  gate: { label: string; needs: ('mic' | 'orientation')[] };
  timer: { skin: TimerSkin; durationMs?: number; onZero?: EndingId };
  hud: { inventoryName: string; hintChannel: HintChannelSkin; notebook: boolean };
  scenes: SceneDef[];
  puzzles: PuzzleDef[];              // id, 장면, 위젯 설정, 정답 판정, 보상
  hints: Record<PuzzleId, HintDef>;  // intro 한 줄 + 3단계
  events: EventDef[];
  endings: EndingDef[];
  assets: AssetBundleDef[];          // 장면별 묶음
  extra?: { initial: unknown; migrate?: (old: unknown) => unknown };
};
```

- 대사는 테마의 `data/script.ts`에 키로 모은다. 대본 문서의 표기(내레이션·메모·조사·획득·시스템)를 그대로 타입으로 쓴다.
- 퍼즐 코드는 위젯을 조립하고 정답만 판정한다. 화면 틀·저장·힌트·타이머는 건드리지 않는다.

## 14. 연출 (GSAP)

- 장면을 나갈 때 그 장면의 GSAP 애니메이션을 모두 정리한다(장면별 context).
- PixiJS 오브젝트는 GSAP PixiPlugin으로 움직인다.
- 공통 연출 모음(`fx/tweens.ts`): 흔들림(오답), 열림(경첩), 켜짐(불), 날아가기(획득), 서서히 떠오르기(인화·편지), 카메라 이동.
- "효과 줄이기" 설정이 켜지면 흔들림·번쩍임을 약하게.

## 15. 성능

- 그림은 장면별 묶음으로 불러오고, 장면을 나오면 내린다. 다음 장면 묶음은 미리 불러오기.
- 텍스처 한 장 긴 변 4096px 이하. 큰 줌 장면은 LOD(1/12 설계 7-3 방식).
- 목표 60fps, 저사양은 30fps 상한 + 화면 배율 1.5.
- 첫 진입(시작 게이트까지) 그림·소리 합계 목표 8MB 이하, LTE에서 5초 안팎.
- 메모리: 동시에 올라간 텍스처 합계 목표 150MB 이하(저사양 Android 기준).

---

## 16. 빌드·배포·테스트

- Next.js 정적 내보내기. HTTPS 정적 호스팅이면 어디든(전체화면·센서·마이크는 HTTPS 필수).
- 개발 중 휴대폰 확인: 같은 와이파이에서 개발 서버 접속은 HTTPS가 아니라 마이크·센서가 막힐 수 있다 → 정적 빌드를 HTTPS 주소에 올려 확인한다.
- 테마 하나씩 독립 실행 가능해야 한다(다른 테마 에셋 없이).
