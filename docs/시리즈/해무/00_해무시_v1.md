# 해무 세 테마 연결 점검 v1

> 대상: 심야 라디오(설계·대본 v1) · 등대지기의 마지막 일지(설계 v1·대본 v1) · 한 땀(설계 v1·대본 v1)
> 점검일: 2026.11.05 · 결정 반영: 2026.11.05 · 작은 고리 반영: 2026.11.06

## 0. 결정 (확정)

1. **"그 등대 말고"의 출처 = (가) 영감 → 도윤.** 영감이 20년 동안 사연에 자주 쓴 말을 도윤이 따라 쓰게 됐다. 대사로는 설명하지 않는다. 물증은 등대지기 P5의 노란 띠지 한 장(2009.2.12).
2. **추천 플레이 순서 표시: 심야 라디오 → 등대지기 → 한 땀.** 해무 목록 화면에 순서 번호와 "이 순서로 하면 더 재미있어요" 한 줄. 잠금은 걸지 않는다(어느 테마든 바로 시작 가능).
3. **해무 전체 클리어 보상: 보류.** (늘봄시와 같은 상태)
4. **작은 고리 3개 넣기** (4장).
5. **제작 결정:** 음성은 기계를 거친 소리만 녹음(대면 대사는 자막), 라디오 곡은 2분 30초 안팎 5곡을 루프·페이드로 늘린다.

## 2. 맞는 것 (확인 완료)

- 등대 불빛 8초 주기: 라디오 P1 창밖 = 등대지기 P1 정답(옛 해도 6초는 함정).
- 등대 불빛이 라디오 시작 무렵에도 돈다: 등대지기 고장은 "주등 → 예비등"이라 항구 안에서는 계속 보임.
- 라디오 02:00~02:03 비상 송출 정사 = 등대지기 배경 큐(무음 2초 → 호출부호 → 녹음 코너 → 해무수산 → 날씨).
- 02:20 무렵 송신 주파수 밀림 = 등대지기 라디오 잡음.
- 영감의 편지 A는 생방송에서 안 읽히고 다음 날 아침 낭독 = 등대지기 에필로그, 노란 띠지 ✓.
- 영감 제복: 등대지기 영수증 『2023.3』 = 한 땀 장부 『0318 노만호』 = 엔딩 A "3년 기다렸어요".
- 진억수 선장(30대): 등대지기 제3해진호 = 한 땀 P3 기념식 바지.
- 해진 8호: 라디오 P1 창밖 "배" = 등대지기 P4 함정 배.
- 카운터 손님: 편지 C(불꽃축제, 경매 끝나고 뛰어감) · B/D(새끼 넷, '두시') · F(졸업 작품 발표) = 한 땀 21:03 · 21:12 · 21:20.
- 광고 문구 "찾아가지 않으신 옷, 아직 기다리고 있습니다" = 라디오 P3 카트리지 = 한 땀 오프닝·엔딩.
- 시스템 구분: 타이머(온에어 시계 / 놋쇠 벽시계 / 실패), 힌트(메신저→무전 / 전성관 / 골무), 가방(가방 / 주머니 / 반짇고리), 저장 키 3개 겹치지 않음.
- 세 테마 모두 아무도 죽지 않고 초자연 없음. 늘봄시 요소 없음. 팔칠구 정체·합격 여부 미공개 유지.
