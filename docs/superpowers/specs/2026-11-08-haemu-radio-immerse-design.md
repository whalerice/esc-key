# haemu-radio 몰입 아트 교체 (슬롯 교체) — Design

날짜: 2026-11-08  
대상: `haemu-radio` (심야 라디오) 파일럿  
기준: `docs/개발/해무_스타일가이드_v1.md`, `docs/개발/해무_에셋목록_v1.md`, `docs/개발/공통엔진_v1.md`

## 문제

기존 `*-art-*` 작업은 네모·원·텍스트 라벨 SVG(와이어프레임)다. 화면이 HTML/회색상자처럼 보여 몰입이 깨진다. 퍼즐·엔진은 이미 동작한다.

## 목표 (합격선)

- 스크린샷만으로 와이어/순수 HTML 크롬이 드러나지 않는다 (방·소품·HUD).
- 플레이 중 “방에 있다” 느낌: 따뜻한 광원 1개, 안개/밤 톤, 핫스팟 시선 유도.
- 기존 퍼즐·세이브·힌트·핫스팟이 깨지지 않는다 (비주얼·스킨만 교체).

비목표: 패럴랙스/시네마틱 FX, 전 테마 동시 교체, 엔진 API 리팩터, 보이스·BGM 교체.

## 결정 요약

| 항목 | 선택 |
|---|---|
| 범위 | 배경 + 소품 + HUD 전부 (파일럿 테마만) |
| 테마 | `haemu-radio` |
| 구조 | 하이브리드 — BG 일러/포토, 소품 리치 이미지, HUD 테마 스킨 |
| 생산 | AI/스톡 믹스 + 단서 마크는 손 고정 |
| 구현 | 접근 1 — 슬롯 교체 (`art.ts` 경로·파일명 유지, 확장자/픽셀만 변경) |

## 아키텍처

엔진·핫스팟 좌표·퍼즐 판정·`ThemeDefinition` 플래그는 고정한다. 바꾸는 것:

1. `public/themes/haemu-radio/rooms/*` — 풀블리드 방 BG
2. `public/themes/haemu-radio/props/*` — 소품 픽셀
3. `src/themes/haemu-radio/art.ts` — 필요 시 확장자만 (`.svg` → `.webp` 등)
4. `haemu-radio` 한정 HUD CSS 오버라이드

`Flow.tsx` 씬 분기·좌표 로직은 건드리지 않는다. `img` src가 `art.ts`를 따르면 확장자 변경만으로 충분하다.

### 시각 레이어 (논리 순서)

1. 방 BG (1920×1080, 광원 1개)
2. 상태 오버레이 (문/램프 등 — 기존 플래그, 작은 추가 에셋만)
3. 인터랙트 소품 (`props/`)
4. 단서 고정 레이어 (생성물 금지)
5. DOM HUD 스킨

폴백: BG 로드 실패 시 기존 flat fill (`scenes/rooms.ts`). 소품 교체 전 1세대 SVG는 `_legacy/` 또는 git 이력으로 유지.

## 에셋 생산

### 방 BG (5) — 현재 씬 슬롯만

게임 씬 키 ↔ 에셋목록 (파일럿 필수 ★):

| 파일 | 씬 | 에셋목록 |
|---|---|---|
| `rooms/control.webp` | `control` 부조정실 | R-BG-02 |
| `rooms/booth.webp` | `booth` 부스 | R-BG-03 |
| `rooms/desk.webp` | `desk` 작가석 | R-BG-05 |
| `rooms/archive.webp` | `archive` 아카이브실 | R-BG-06 |
| `rooms/roof.webp` | `roof` 옥상 | R-BG-08 |

파일럿 비범위 (슬롯 없음 / 별도 작업): R-BG-01 복도, R-BG-04 창밖 뷰 레이어, R-BG-07 옥상 계단, R-BG-09 엔딩 원경. 상태 변화(ON AIR·도윤 착석·송신 램프)는 통짜 BG 재생성 대신 작은 오버레이 PNG/SVG로 처리한다.

규칙:

- 팔레트·빛: 스타일가이드 §1 (밤바다, 안개, 방송빨강 ON AIR).
- 논리 중앙 1680×860 안에 단서 자리. HUD 코너에 단서 금지.
- BG에 UI 라벨 텍스트(“부조정실” 등)를 굽지 않는다.
- 시점: 눈높이 정면 + 살짝 3/4 (가이드 §3-3).

### 소품

- 파일명 유지 (`radio`, `cuesheet`, `key-*`, …). 포맷은 WebP/PNG 또는 리치 SVG.
- 손때·놋쇠·테이프 질감 (가이드 §4). 질감은 손이 닿는 물건 위주.
- 탭 최소 크기는 히트박스가 보장 (논리 132×132). 그림은 그보다 작아도 된다.

### 단서 고정 (머지 게이트)

생성 AI에 맡기지 않는다. 베이스 위에 확정 SVG 오버레이를 얹거나 소품에 손으로 굽고 `CREDITS.md`에 `clue-locked`로 표기한다.

| 마크 | 용도 |
|---|---|
| 빨간 등대 이중 동그라미 | P1 |
| 라디오 숫자창 깨진 9 | P2·P5 |
| 큐시트 낙서·슬롯 토큰 | 큐 퍼즐 |
| 열쇠 실루엣 구분 (배/부표/갈매기 등) | 인벤 식별 |

### 라이선스

- Unsplash: 채택 시 `downloadLocation` 호출. 핫링크·무단 깃 대량 저장 금지.
- Pixabay: 프로젝트 `assets:collect --download` 규칙 준수.
- AI: 상업/게임 이용 가능 출처만. 모델·시드·프롬프트 요약을 `public/themes/haemu-radio/CREDITS.md`에 기록.

## HUD 스킨

`haemu-radio` 플레이 중에만 적용.

- 토큰: 종이 미색 `#E9E2D2`, 바랜 잉크 `#3B3A36`, 놋쇠 `#B08D4F`, 방송빨강 `#D9473A`.
- 대상: 가방, 힌트(메신저/무전), 시계·실패, 캡션 띠, 테마 게이트/세로 안내가 테마 CSS에 묶인 경우.
- 엔진 공통 HUD 컴포넌트 API는 바꾸지 않는다. 클래스/테마 data 속성 오버라이드만.

## 검증

1. **시각** — 5방 스크린샷: 와이어 도형·굽힌 UI 라벨·기본 브라우저 크롬 느낌 없음.
2. **기능** — P1~엔딩 스모크, 인벤 식별, 힌트 3단·채널 전환, 세이브/이어하기.
3. **터치** — 가로 높이 360 CSS px, 핫스팟 44px, 조작 금지 띠 유지.
4. **접근성** — 색 단서에 모양/글자 보조 유지 (가이드 §2).
5. **단서 게이트** — 위 고정 마크 체크리스트 전부 통과 후에만 머지.
