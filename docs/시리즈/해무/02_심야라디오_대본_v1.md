# 심야 라디오 — 전체 대본 v1

`심야라디오_설계_v1.md`의 퍼즐 구조(퍼즐 8개, 엔딩 2개)를 따르는 장면 대본. 모든 대사의 기준 문서. 채 선배·도윤 힌트 전문(12장)도 이 문서가 기준이다.

> 2026.11.05 해무 연결 점검 반영(`해무시_v1.md`): 편지 A 문구("올겨울", "이 시간 방송"), 4장 3번 독백, 8장 9번 1번 사연 끊김, 부록 E-1 옥상 농담, 규칙에 "그 등대 말고" 출처.

표기: [화면] · [소리] · 「독백」 플레이어 속말 · "대사" 인물 · 『자막』 화면 텍스트 · [조사] 탭 시 텍스트 · [획득] 가방 알림 · [수첩] 수첩 자동 기록 · (메신저) 선배 메시지 배너 · (무전) 무전 배너 · ((방송)) 라디오·스피커로 나가는 소리
독백은 화면 아래 내레이션 띠에 한 줄씩, 탭으로 넘김. 퍼즐 조작 중에는 독백을 띄우지 않는다(오답 피드백 한 줄은 예외). 옛 방송과 무전은 청각 보조 모드가 아니어도 자막을 띄운다.

## 플레이어의 감정선 (작가 메모)

| 구간      | 플레이어가 믿는 것              | 독백의 결                            |
| --------- | ------------------------------- | ------------------------------------ |
| 오프닝~P1 | 첫 출근, 실수하면 안 된다       | 긴장. 존댓말 섞인 혼잣말             |
| P2~P3     | 방송을 지켜야 한다              | 급하고 짧다. 작은 성공에 안도        |
| P4        | 이상한 빈칸                     | 일하다가 멈칫. 호기심                |
| P5~P6     | 15년 전 한 사람                 | 조용해진다. 팔칠구에게 마음이 간다   |
| P7        | 도윤이 살아 있다, 갇혔다        | 안도와 웃음. 도윤과 처음 말을 섞는다 |
| P8        | 이 방송을 끝까지 닿게 하고 싶다 | 짧고 단단하게                        |

규칙

- 플레이어는 이름이 없다. 도윤은 "작가님", 선배는 "후배님"이라 부른다.
- 팔칠구의 합격 여부, 본명, 나이를 누구도 말하지 않는다. 플레이어도 추측하지 않는다.
- 팔칠구 사연은 무겁지 않게. 병·사고·죽음에 대한 말은 하지 않는다.
- 늘봄시의 지명·인물은 말하지 않는다.
- 도윤의 말버릇 "그 등대 말고"는 해무 큰 등대 영감(필명 '등대지기 영감')이 20년 동안 사연에 자주 쓰던 말이 옮은 것이다(등대지기 테마 설정). 이 테마 안에서는 출처를 설명하지 않는다.
