> 기준 문서: 해무 프로젝트 문서, 심야 라디오 개발 기획서. 모든 대사는 `심야라디오_대본_v1.md`가 기준이다.

**기획서 → 설계 v1에서 공통 엔진에 맞춰 바꾼 점**

- 남은 시간은 엔진 `Timer`의 새 스킨 **온에어 시계(02:00 → 02:30)** 로 표시한다. 배경 곡은 엔진 `Events`의 타이머 지점으로 바꾼다 (9-4).
- 힌트 채널은 **선배 작가 메신저**(P1~P6) → **도윤 무전**(P7~P8)으로 이어진다. 엔진 힌트 채널에 "도중에 채널 모양 바꾸기"가 필요하다 (9-6, 13장).
- 회전은 엔진 `회전 드래그`(한 손가락)를 기본으로, **두 손가락 회전**을 엔진 제스처에 추가한다. 튜닝 노브와 세로 페이더는 새 위젯으로 엔진에 넣는다 (13장).
- 옛 방송(P2·P5·P8 소리 단서)은 HTML5로 튼다. 잡음·거리 필터만 Web Audio. 무음 스위치는 시각 대체(자막·램프·청각 보조)로 진행한다 (9-5, 엔진 11·19-6).
- 백그라운드 복귀 처리, 저장, 결과 카드는 엔진 기본값을 따른다. 기획서의 "방송 재개 버튼"은 엔진 시스템 오버레이로 넣는다.
- 스토리, 퍼즐 8개, 정답, 엔딩은 기획서 그대로다.

## 0. 설계 원칙

- 반전은 하나: **사라진 DJ는 15년 전 한 청취자와의 약속을 지키려고 옥상에 올라갔다가 갇혔다.**
- 초자연 요소 없음. 87.9 주변의 옛 방송은 도윤이 걸어 둔 시험 송출이다.
- 결말 원칙: **팔칠구가 들었는지는 끝까지 아무도 모른다.** 편지에도 합격 여부를 적지 않는다.
- 팔칠구의 사연은 무겁지 않게(컵라면, 짝사랑, 모의고사). 병·사고·죽음 없음.
- 시그니처 조작: **주파수 다이얼 회전**. P2(라디오를 방송에 맞춤) → P5(방송 사이를 찾음) → P8(방송을 라디오에 맞춤)로 세 번 다르게 쓴다.
- 반복 모티프: **두 개의 등대.** P1 함정 → P7 함정 → 엔딩 원경. 도윤의 말버릇 "그 등대 말고".

## 6. 퍼즐 상세

### P1. 등대가 알려주는 순서 (튜토리얼)

- 부스 문 키패드 4자리. 방송 중 자동 잠김. 도윤은 몇 년 전 술 취한 청취자가 생방송 중에 들어와 노래를 부른 뒤로 비밀번호를 매일 바꾼다.
- 단서: 인수인계 메모(분 끝자리 규칙, "등대가 알려준다"), 큐시트 낙서 4개, 창밖.
- 창밖: 큰 등대 불빛이 8초 주기로 왼쪽→오른쪽. 비추는 순서 **배 → 빨간 등대 → 부표 → 갈매기**.
- 풀이: 배 02:14→4, 빨간 등대 02:25→5, 부표 02:03→3, 갈매기 02:18→8 → **4538**.
- 함정: 낙서 속 빨간 등대 때문에 5로 시작하기 쉽다. 5로 시작하는 오답이면 키패드 옆 포스트잇이 흔들리며 "그 등대 말고. 저 멀리."가 보인다(도윤 글씨, P7에서 회수). 결과 카드 "포스트잇 발견".
- 복선: 책상의 뜯긴 봉투("갈곶리 우체국" 소인, 속은 비어 있음), 식은 커피(P7).
- 해결: 문이 열리고 부스에서 오프닝 시그널, 빈 DJ 의자.

### P2. 귀로 맞추는 주파수 (회전 튜토리얼)

- 탁상 라디오로 87.9 에어체크. 마스킹테이프 "숫자 창 고장. 귀로 맞출 것."
- 숫자 창은 **마지막 한 자리만** 켜지는 고장(87.9에서도 "9"만). P5의 단서가 된다.
- 조작: 노브 확대 → 처음 1회 회전 가이드. 한 손가락 원 그리기 또는 두 손가락 회전. 한 바퀴 약 1MHz, 0.1 단위 딸깍.
- 판정: 87.9 ±0.05에 1초 → 초록 램프, 잡음이 걷힘.
- 시각 대체: 시그널 미터 바늘(87.9에 가까울수록 오른쪽).
- 떡밥: 87.55~87.65 처음 진입 시 젊은 도윤 목소리 한 마디(1회만).
- 해결: 오프닝 시그널이 끝나 가고 "무음 3초 후 방송 사고" 경고등.

### 7-1. 엔딩 A 「제 자리」 (P8 완료)

### 7-2. 엔딩 B 「송출 종료」 (시간 초과)

- 시계 0:00(02:30) → 어느 장면에서든 입력 잠금 → 송출 종료음.
- 송신기를 맞추지 못한 상태: 도윤이 잡음 속에서 팔칠구의 편지를 끝까지 읽는 목소리만 희미하게. 갈곶리에 닿았는지 더더욱 알 수 없다.
- P6 이전에 끝난 경우: 빈 부스에서 자동 송출 곡이 끝나고 무음, 도윤 목소리 없음.
- 문자 알림 없음. 잡음 → 암전 → "처음부터 다시" 버튼(이어 하기 없음, 저장 초기화).

### 7-3. 결과 카드

- 걸린 시간, 남은 온에어 시간, 힌트 수("선배에게 메시지 n번, 무전 n번"), 본 엔딩 도장, 함정 발견 2종(포스트잇 / 빨간 등대 열쇠), 들은 옛 방송 n/4.
- 공유 이미지: 엔딩 A는 안개 낀 창밖 원경(등대 불빛), B는 꺼진 ON AIR 램프. 편지 본문과 팔칠구 필명은 넣지 않는다.

### 9-5. 사운드 (이 테마의 핵심)

- **재생 방식**: P2·P5·P8의 옛 방송(소리 단서)은 HTML5로 재생한다(엔진 11장, 19-6). 지원 Safari에서는 시작 게이트 탭에서 오디오 세션을 재생용으로 설정해 무음 스위치에 묻히지 않게 한다.
- **Web Audio**: 잡음 섞기와 장면별 거리 필터만. 단서가 아니다. 옛 방송 볼륨 크로스페이드를 Web Audio로 하지 않는다.
- **무음 스위치**: 단서는 HTML5라 무음에도 나야 한다. 안 나오면 시각 대체로 진행한다. 자막, 시그널 미터·램프, P5 수첩 자동 기록, P6 재생 자막. 청각 보조 모드.
- **청각 보조 모드**: 모든 대사·옛 방송 자막, 시그널 미터·램프로 튜닝, P5 수첩에 D-day 자동 기록, P6 재생 중 자막. 소리 없이 끝까지 갈 수 있어야 한다.
- **동시 재생 수**: P5는 잡음(Web Audio) + 현재 방송 + 옛 방송 4. 저사양 Android에서 확인. 옛 방송은 HTML5로 따로 틀고, 안 들리는 구간은 바늘·램프로 같은 위치를 보여 준다.
- **무전·마이크 테스트 음성**: 잡음 루프 위에 겹침. 엔진 덕킹(배경 40%).
- 볼륨 채널: 배경(큐시트 곡) · 효과음 · 음성(도윤, 옛 방송 포함).

### 9-6. 힌트 채널

- P1~P6: **채 선배 메신저**. 아이콘은 말풍선. 마지막 방송을 집에서 듣고 있는 선배가 답장한다. 무음 경보가 나면 힌트를 열지 않아도 한 번 먼저 메시지가 온다("방금 무음 났어요!!").
- P7~P8: **도윤 무전**. P6 해결 이벤트로 아이콘이 무전기로 바뀐다. 엔진에 `hint:channel=` 이벤트 추가 필요.
- 첫 연결 한 줄(`hint.intro`)과 3단계 전문은 대본 12장.
- 정체 감지 4분.
