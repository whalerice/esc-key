규칙

- 플레이어는 이름이 없다. 사장은 끝까지 "꼬마"라고 부른다. 플레이어는 "사장님".
- 사장은 말이 빠르고 잔소리가 섞인다. 다정함은 말보다 행동으로.
- 엄마는 끝까지 얼굴이 나오지 않는다. 쪽지와 전화 목소리뿐.
- 팔칠구는 등장하지 않는다. 늘봄시의 지명·인물은 말하지 않는다.
- 카운터 손님들은 필명이나 정체를 직접 말하지 않는다. 라디오를 들은 사람만 알아챌 만큼만.
