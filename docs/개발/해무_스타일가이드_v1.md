## 0. 한 줄

**"안개 너머로 새어 나오는 작은 불빛."** 넓은 곳은 차갑고 흐리게, 사람이 지키는 자리만 따뜻하고 또렷하게 그린다.

- 키워드: 안개, 새벽, 젖은 표면, 놋쇠, 종이, 손때, 작은 불빛 하나
- 늘봄시와 구분: 늘봄시가 "동네의 낮과 저녁"이라면 해무는 "바닷가의 밤". 늘봄시 색·소품·간판체를 가져오지 않는다.
- 세 테마가 한 시리즈로 보이게 **공통 바탕(안개·밤바다·종이·놋쇠)**을 쓰고, 테마마다 **불빛 하나의 색**으로 구분한다.

| 테마 | 시간 | 지키는 불빛 | 테마 색 |
|---|---|---|---|
| 심야 라디오 | 새벽 2시 | ON AIR 램프 | 방송 빨강 |
| 등대지기 | 새벽 2시 | 등대 빛 | 등명 호박색 → 주등 흰빛 |
| 한 땀 | 밤 9시 | 수선집 형광등 | 실 남색 + 바다유리 초록 |

### 1-3. 빛의 규칙
- 장면마다 **따뜻한 광원은 하나**만 강하게. 나머지는 안개 색으로 눌러 둔다.
- 따뜻한 불빛이 닿는 곳에 단서와 사람이 있다. 시선 유도를 빛으로 한다.
- 엔딩 A로 갈수록 따뜻한 빛이 넓어진다(라디오: 송신탑 초록 → 창밖 등대 / 등대지기: 호박 → 흰빛 / 한 땀: 형광 → 아침 창가). 엔딩 B는 따뜻한 빛이 꺼지고 안개 색만 남는다.

## 2. 접근성 규칙 (색만으로 구분하지 않기)

색으로 푸는 단서는 **모양이나 글자를 함께** 둔다. 해무에는 색 단서가 세 곳 있다.

| 테마 | 단서 | 색 외에 함께 둘 것 |
|---|---|---|
| 등대지기 P2 | 배전반 레버 색 = 층 색띠 | 레버 테이프와 층 띠에 **층 숫자**를 작게(1~6). 소금기에 반쯤 지워진 숫자로 그려 분위기 유지 |
| 등대지기 P5 | 띠지 빨강·파랑·노랑 | 띠지 끝 모양을 다르게: 빨강 ▽(뾰족), 파랑 ━(일자), 노랑 ◠(둥근) |
| 한 땀 P2 | 리본 5색 = 선반 | 리본 매듭 모양을 다르게: 빨강 나비매듭, 파랑 한 번 묶음, 초록 두 번 묶음, 노랑 고리, 남색 철망 선반 자체로 구분 |
| 심야 라디오 P1 | 빨간 등대만 빨간 펜 | 빨간 등대 낙서는 굵은 선 + 이중 동그라미 |

- 이 규칙은 퍼즐 답을 바꾸지 않는다. 각 테마 설계 v2에 "보조 표시"로 반영됨.
- 램프(빨강/초록) 상태는 색 + 밝기 차이 + 아이콘(✓)을 함께.

## 3. 화면 구성

### 3-1. 영역
- 논리 화면 1920×1080. **단서는 가운데 1680×860 안**(좌우 120, 위 60, 아래 160 여백)에 둔다.
- HUD와 겹치는 자리에는 단서를 두지 않는다: 왼쪽 위(시계·실패), 오른쪽 세로 띠(부품함), 오른쪽 아래(힌트 아이콘), 아래 22%(내레이션 띠가 올라올 수 있음).
- 조작 금지 띠(좌우 24px·아래 20px, CSS 기준)는 논리 좌표로 약 좌우 72·아래 60. 그림은 깔아도 되지만 탭 대상은 금지.

### 3-2. 크기 (높이 360 CSS px 기기 기준, 1 CSS px ≈ 논리 3px)
| 대상 | 최소 크기(논리 px) |
|---|---|
| 탭 대상(핫스팟) | 132 × 132 (엔진 44px) |
| 그림에 굽는 글씨(명판, 라벨) | 글자 높이 42 이상, 단서 숫자는 54 이상 |
| 클로즈업 패널 안 숫자·눈금 | 글자 높이 60 이상 |
| 손글씨 DOC | DOM이므로 기본 16 CSS px, "글자 크게" 20 |

- 작은 글씨가 필요한 소품(장부, 일지)은 장면에서는 덩어리로만 보이게 그리고, 탭하면 DOC 카드로 읽는다.

### 3-3. 시점
- 장면 배경: 사람 눈높이 정면 + 살짝 내려다보는 3/4. 방 전체가 한 화면에 들어오게.
- 클로즈업: 정면 평면(위에서 내려다보거나 정면). 조작 대상이 원근 때문에 찌그러지지 않게.
- 원경(창밖·난간 파노라마): 수평선을 화면 위 40% 근처에. 안개 층이 수평선 아래부터 짙어진다.

## 4. 선과 질감

- **선**: 외곽선은 가늘고 색이 있는 선(검정 대신 깊은 밤 `#12191F`나 같은 계열 어두운 색). 먼 곳은 선을 빼고 면으로만.
- **면**: 평면 채색 + 부드러운 그라데이션 1단. 사실적 렌더링이나 강한 광택은 쓰지 않는다.
- **질감**: 종이 결, 젖은 표면의 번들거림(하이라이트 한두 줄), 놋쇠의 닳은 부분, 천의 짜임. 질감은 전체에 깔지 말고 손이 닿는 물건에만.
- **손때**: 오래 쓴 물건은 모서리가 닳고 색이 바랜다(도윤의 콘솔, 영감의 열쇠함, 사장의 재봉틀). "사람이 오래 지킨 자리"가 그림에서 보이게.

## 5. 안개 표현

- 레이어 2장(앞·뒤)이 다른 속도로 천천히 흐른다(공용 H-FX-01). 효과 줄이기면 정지 1장.
- **단서가 안개에 묻히지 않게**: 퍼즐 단서와 핫스팟 위에서 안개 불투명도 상한 35%. 등대지기 탐조등 빛 안에서는 20%.
- 안개 색은 장면의 따뜻한 광원 쪽으로 살짝 물든다(등대 빛 근처는 흰빛, 송신탑 근처는 붉게).
- 한 땀은 실내라 안개가 없다. 복도 창과 엔딩 시장 밖에서만 쓰고, 그 대신 형광등의 뿌연 빛 번짐으로 같은 결을 낸다.

## 6. 인물

### 6-1. 공통
- 비율: 약 6.5~7등신, 사실적에 가깝되 단순화. 얼굴은 눈·코·입을 작게, 표정은 눈썹과 입꼬리로.
- 인물은 장면의 따뜻한 빛 안에 둔다. 실루엣만으로 누군지 알 수 있게 소품을 하나씩: 도윤(헤드폰·점퍼), 영감(낡은 근무 점퍼·보온병), 사장(돋보기·팔토시), 진억수(방수 재킷·모자).
- 표정 시트: 인물당 4개 안팎(에셋 목록 기준).

### 6-2. 보여 주지 않는 얼굴
| 인물 | 규칙 |
|---|---|
| 팔칠구 | 어떤 테마에서도 그리지 않는다. 손글씨와 목소리 없는 글만 |
| 엄마(한 땀) | 얼굴 금지. 1999 뒷모습, 2026 어깨와 손 |
| 마지막 손님 3(한 땀) | 뒷모습·옆모습, 얼굴은 빛 번짐으로 흐리게 |
| 채 선배(라디오) | 메신저 아이콘만 |
| 플레이어(세 테마) | 손만. 소매로 테마 구분(신입 작가: 카디건, 주무관: 공무원 점퍼, 꼬마→어른: 코트 없이 니트) |

### 6-3. 공유 인물
- 영감은 등대지기와 한 땀에서 **같은 옷**(낡은 근무 점퍼). 한 땀에서는 찾아간 제복 커버를 팔에 든다.
- 진억수는 한 땀에서 처음 그린다. 등대지기 무전 목소리와 나이·말투가 맞게(30대, 방수 재킷).

## 7. 손글씨

모든 손글씨 DOC는 인물마다 다른 글씨체를 쓴다. 웹폰트는 상업 이용과 웹 임베드가 되는 라이선스(예: OFL 계열 한글 손글씨체)로 고르고, 고르기 전에 라이선스를 확인한다.

| 쓰는 사람 | 결 | 도구 느낌 | 나오는 곳 |
|---|---|---|---|
| 도윤 | 크고 기울어짐, 획이 빠름 | 굵은 사인펜 | 포스트잇, 테이프, 매뉴얼, 쪽지 |
| 채 선배 | 둥글고 또박또박, 이모티콘 | 볼펜 | 인수인계 메모 |
| 팔칠구 2011 | 작고 반듯, 수험생 | 샤프 | 장부·옛 편지(그림) |
| 팔칠구 2026 | 2011과 같은 사람이지만 조금 풀린 획 | 볼펜 | 오늘의 편지 |
| 영감 | 각지고 꾹꾹 눌러 씀, 숫자 또박또박 | 연필(일지), 볼펜(편지) | 열쇠함, 쪽지, 일지 전부 |
| 사장 | 빠른 흘림 + 그림 기호 | 볼펜, 초크 | 장부, 메모, 카드 |
| 엄마 | 단정하고 가지런함 | 볼펜 | 쪽지 |
| 꼬마(11살) | 삐뚤빼뚤, 느낌표 여러 개 | 매직 | 필통 뚜껑 |
| 플레이어 | 세 테마 같은 글씨(시리즈 공통 "나") | 볼펜 | 등대지기 일지·인수서, 한 땀 ✓ |

- 같은 사람의 글씨는 테마가 달라도 같은 폰트(영감: 등대지기 일지 = 한 땀 장부 속 서명).
- 인쇄 글씨(큐시트, 공고, 명판, 신호 카드)는 바랜 고딕 하나로 통일.

## 8. 소품

- **놋쇠 계열**(노브, 전성관, 명판, 단추 게이지, 시계 테): 같은 놋쇠 색과 닳은 하이라이트 규칙. 세 테마를 잇는 재질.
- **종이 계열**(편지, 일지, 장부, 번호표, 쪽지): 종이 미색 바탕, 오래된 것일수록 누렇고 가장자리가 해짐. 연도 차이를 종이 색으로 보여 준다(2026 편지 < 2011 장부 < 1999 쪽지 순으로 누렇게).
- **띠지·리본·라벨**: 2장 접근성 규칙의 모양 구분을 지킨다.
- **화면 속 화면**(감시반 모니터, 문자 수신함, 메신저): 저해상도 느낌 없이 단순한 평면 UI. 글자는 DOM으로 겹친다.

## 9. 움직임

- 등대 불빛 8초 주기(라디오 창밖, 등대지기 당직실 창·엔딩): 같은 타임라인을 공유해 "같은 등대"로 보이게.
- 움직임은 느리게: 안개 흐름, 릴 회전, 렌즈 회전, 형광등 웅. 빠른 움직임은 오답 흔들림과 연출 순간만.
- 깜빡임(형광등, 경고등, 램프)은 1초에 3번을 넘지 않는다. 효과 줄이기면 밝기 변화만.

## 10. 결과 카드와 공유 이미지

- 도장: 테마마다 모양이 다른 도장(라디오: 우체국 소인형 원 / 등대지기: 사각 관인형 / 한 땀: 단추 모양 원). 글씨는 바랜 고딕.
- 공유 이미지: 스포일러 금지 목록(각 대본 11장)을 지킨다. 인물 얼굴·편지 본문·쪽지 본문·팔칠구 필명을 넣지 않는다.
- 세 장을 나란히 놓으면 이어지게: 라디오 A(창밖 등대 빛) → 등대지기 A(등대에서 본 빛줄기) → 한 땀 A(초록 단추). 공통 안개 띠를 아래에 깐다.

## 11. 하지 말 것

- 순수 검정 `#000`과 순수 흰색 `#FFF` (가장 어두운 색은 깊은 밤, 가장 밝은 색은 주등 흰빛).
- 네온·채도 높은 원색, 늘봄시 색·간판체.
- 공포 연출(갑자기 튀어나오는 얼굴, 피, 일그러짐). 해무는 쓸쓸할 수는 있어도 무섭지 않다.
- 실제 상표·로고·실존 방송사·실존 지명 간판.
