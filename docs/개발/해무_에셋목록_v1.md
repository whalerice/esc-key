## 0. 읽는 법

- ID: `R`(라디오) · `L`(등대지기) · `T`(한 땀) · `H`(해무 공용) + 종류 + 번호.
  - `BG` 장면 배경 · `CU` 클로즈업·퍼즐 패널 · `IT` 부품함 아이템 · `CH` 인물 · `UI` HUD·결과 카드 · `FX` 연출 그림 · `DOC` 문서(DOM으로 그리는 글) · `MU` 음악 · `AM` 환경음 · `SE` 효과음 · `VO` 음성
- 상태: 같은 그림의 변형(불 켜짐/꺼짐, 열림/닫힘). 변형은 따로 세지 않고 "상태" 칸에 적는다.
- 글씨 원칙(엔진 2장): 두 줄 이상 글은 `DOC`(DOM 텍스트, 종이 질감 배경만 그림). 한 줄짜리 소품 글씨(명판, 라벨)는 그림에 굽는다.
- 우선순위: ★ 첫 플레이 테스트(회색 상자 다음 단계)에 꼭 필요 / ☆ 나중에 다듬어도 됨.
- ◇ 표시: 색 단서 보조 표시가 필요한 그림(스타일 가이드 2장).

## 2. 결정 (2026.11.06)

1. **음성 녹음 범위 = 기계를 거친 소리만.** 라디오 방송·카트리지·옛 방송·무전·전성관·전화·안내 방송을 녹음한다. 얼굴 보고 하는 대사는 자막 + 짧은 숨소리·감탄(효과음 취급). 약 170줄.
   - 한 땀 사장 대사도 자막(추가 녹음 안 함). 사장은 짧은 감탄·웃음·혀 차는 소리 3~5개만 효과음으로.
2. **라디오 곡 분량 = 2분 30초 안팎 원곡 5곡 + 루프·페이드.** 큐시트 슬롯(4·7·4·7·2분)은 `RadioBed`가 루프 지점과 크로스페이드로 채운다. 작곡 의뢰 시 "자연스럽게 반복되는 구간(루프 포인트) 표시"를 요청한다.
3. **색 단서 보조 표시**(스타일 가이드 2장)를 그림 단계에서 넣는다. 해당 항목은 ◇.
4. 그림 스타일은 `개발/해무_스타일가이드_v1.md`를 따른다. 이 목록은 "무엇을 그리나"만 다룬다.
