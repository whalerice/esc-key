## 0. 30분 설계 원칙

- 퍼즐 8개 + 피날레(이름표 쓰기) 1개, 일직선. 오해 1개 → 반전 1개.
- **아무도 죽지 않는다. 초자연도 없다.** 모든 사건은 현실 논리로 설명된다. 늘봄시 연결고리도 이 원칙을 깨지 않는다(붉은 방의 붉은 여자는 이 테마에 나오지 않는다).
- 시그니처 트릭 ① **입김**: 유리에 입김을 불면 30년 된 손가락 자국이 떠오른다. (실제로 있는 현상: 손 기름 자국 위로 김이 다르게 서린다)
- 시그니처 트릭 ② **하룻밤 꽃**: 시작할 때 보온 매트에 올린 월하미인 봉오리가 플레이 내내 조금씩 열리다가 반개에서 멈춘다. 마지막 퍼즐(P8)에서 하윤이 직접 피워 낸다. 처음(P1) 켠 불을 마지막(P8)에 끄는 대칭.
- 시간 제한 = **온실 온도계.** 14°C에서 0°C까지. 온도가 내려갈수록 화면 가장자리에 성에가 번진다.
- 톤: 따뜻하고 서정적. 가족·입문자용. 마지막에 울컥, 무섭지 않게.

## 1. 이야기

12월 14일 밤 22:40, 첫 한파. 늘봄시 송현동 한결대학교 식물원 유리온실(1971년 준공, 내년 봄 폐쇄 예정)의 보일러가 멈췄다. 은퇴한 식물학자 윤석주(72)는 밤마다 온실을 지키다 오늘 보일러를 고치려다 넘어져 한결대병원에 입원했다.

15년 넘게 연락을 끊고 지낸 딸 윤하윤(37, 플레이어)에게 음성 메시지가 남아 있다.

> "하윤아. 온실 열쇠는 경비실에 있다. 다 살릴 필요 없어. 하나만, 하나만 살려다오. 도착하면 맨 먼저 작업대 위 화분을 매트에 올리고."

하윤은 "하나"가 아버지 평생의 연구 대상인 **희귀 난초**라고 생각한다. 아빠는 끝까지 식물 걱정이구나, 하면서.

- 오해(P3, 약 10분): 난초 유리장을 열면 카드 한 장. "이건 아니다. 이건 내가 없어도 학교가 살린다."
- 반전(P6, 약 20분): 아버지가 말한 "하나"는 육묘실 구석의 나무 상자 하나. 그 안의 볼품없는 화분 일곱 개는 1996년 일곱 살 하윤이 심고 크레용으로 한 글자씩 적은 **「아 · 빠 · 봄 · 에 · 또 · 올 · 게」**. 하윤은 다시 오지 않았고, 그 일 자체를 잊었다. 아버지는 30년 동안 씨를 받고 다시 심어 그 편지를 해마다 피웠다.
- P8: 아버지가 올해는 직접 들고 가려던 여덟 번째 화분(월하미인)이 반쯤 열리다 멈춰 있다. 아버지가 적어 둔 방법대로 하윤이 피워 낸다.
- 피날레: 이름표는 비어 있고 봉투에 "네 차례". 하윤의 답장.

### 늘봄시 안에서의 위치 (v3)

- 장소: 늘봄시 송현동, 새말선 **송현역** 근처 언덕. 식물원과 한결대병원이 같은 캠퍼스에 있다.
- 시점: 2026년 12월 14일. 늘봄시 테마 중 1/12(늦가을) 다음, 막차 이후(12.24)보다 열흘 앞.
- 이 겨울 늘봄시에서 끝나는 것 두 가지: 이 유리온실(내년 봄 폐쇄)과 2009년식 새말선 전동차(12월 24일 퇴역).

## 5. 퍼즐 상세

### P1. 하룻밤 꽃 (튜토리얼)

- 전실 작업대: 큰 봉오리 하나를 단 월하미인 화분. 화분에 끼운 쪽지(아버지 글씨) "매트 위로. 오늘 밤 핀다." 이름표는 비어 있다.
- 작업대 아래 보온 매트를 끌어와 펼치고, 화분을 드래그해 올린다.
- 콘센트 3개: 회색 2개에는 "보일러 연동 — 고장" 테이프, 노란 1개에 "비상". 플러그를 노란 콘센트로 드래그. 회색에 꽂으면 매트 램프가 안 켜진다.
- 해결: 매트 램프 점등, 화면 왼쪽 위 온도계 옆에 **봉오리 아이콘**이 상주(실시간 개화 진행 표시). 온도계가 14.0°C에서 하강 시작.
- 배우는 것: 탭, 드래그, 확대. 설명 문구 없이.

### P2. 비상 온풍기

- 중앙홀 문이 잠겨 있다. 무전기 남 씨: "열쇠꾸러미요? 교수님이 보일러실 공구함에 두시던데."
- 보일러실: 공구함은 비상 온풍기 옆, 온풍기가 꺼져 있어 공구함 전자 걸쇠가 잠김(온풍기와 같은 전원 계통).
- 벽 점검표(아버지 글씨): "비상 온풍기 — 압력 낮은 밸브부터 연다. 높은 것부터 열면 역류."
- 밸브 4개, 각 위에 계기판. 확대하면 바늘: 파랑 0.8 · 초록 1.6 · 노랑 1.2 · 빨강 2.1 (화면 배치는 초록·빨강·파랑·노랑 순으로 섞음).
- 정답: **파랑 → 노랑 → 초록 → 빨강**. 틀리면 '퓨슉' 소리, 밸브 전부 잠김(재시도).
- 해결: 온풍기 가동, 공구함 열림 → 열쇠꾸러미. 보상으로 온도계가 **3분간 멈춘다**(엔진 `timer.pause(180000)`).
- 복선: 보일러실 바닥에 흙 자국이 옆 육묘실 쪽으로 이어진다. 육묘실 문은 번호 자물쇠.

### P3. 난초 유리장 (오해)

- 중앙홀 한가운데 유리장, 아버지 평생의 난초. 이름표는 "Paphiopedilum **\_\_** Yoon, 1998", 종소명 부분이 긁혀 지워져 있다.
- 유리장 자물쇠: 알파벳 7칸, 라벨 "이 아이 이름".
- 중앙홀 책상 위 액자: 1998년 논문 첫 장. 제목에 신종 이름 **Paphiopedilum hayunae**. 아래 작은 글씨 어원 항목(영문 한 줄, 확대해야 보임): 딸 이름을 따서 지었다는 내용.
- 정답 **HAYUNAE** (엔진 알파벳 키패드, 대소문자 무시).
- 하윤 독백: 「남들한테는 이렇게 잘도 말했네.」
- 유리장 안: 카드 **"이건 아니다. 이건 내가 없어도 학교가 살린다."** + 손때 묻은 노트 『육묘 기록』(어린잎 스케치, 씨앗 스케치, 개화 달력, 겉표지 안쪽에 "육묘실 문 — 그날").
- 남 씨 무전(자동): "교수님은 난초보다 뒤쪽 육묘실에 더 오래 계셨어요. 밤새."
- **v3 늘봄시 소품 (조사만, 풀이와 무관)**
  - 논문 액자 옆 작은 가족사진 액자(L1). 탭하면 독백, 뒤집으면 도장 "명화사진관 · 1994.11". 출입문은 사진 밖이다(붉은 방의 붉은 여자는 이 컷에 없다).
  - 중앙홀 게시판의 지난 행사 포스터 "가을 화분 나눔 — 윤석주 교수"(L6). 탭하면 독백.
  - 두 소품 모두 P3 해결 전에도 후에도 볼 수 있다. 하윤의 오해 결("남들한테는 잘한다")을 거드는 방향으로 독백을 쓴다(대본 3장).

### P4. 닦지 마시오 (시그니처 ①)

- 육묘실 문 번호 자물쇠 4자리. 노트 메모 "그날"뿐.
- 문 옆 유리벽 한 장에만 오래된 종이 "닦지 마시오 — 윤". 다른 유리는 다 깨끗한데 이 한 장만 뿌옇다.
- 입김 불기: 유리를 확대하면 하단에 "후— 불어 보세요" 안내. 마이크에 불면 유리에 김이 서리며 자국이 떠오른다. 권한 거부·마이크 없음 → 유리를 1.5초 길게 누르면 같은 연출.
  - 떠오르는 것: 삐뚤빼뚤한 손가락 글씨 **"하윤"**, 그 옆 가로 금 하나와 어른 글씨 "112cm", 아래 **"96.12.14"**.

### P7. 2011년의 방법

- 일지: 1997년부터 2026년까지 봄마다 한 줄. **"일곱 다 피었다. 안 왔다."** 반복. 가로 화면에서 펼친 공책 두 쪽, 세로 스크롤로 넘긴다.
- **2011년 2월 22일**(하윤의 졸업식) 장만 길다.
- 퍼즐: 아버지가 했던 방법 그대로 상자를 포장한다.
  1. 보일러실 온수 꼭지에서 **물주머니 2개 채우기**
  2. 상자 **양옆에 물주머니**
  3. 벽에 걸린 **아버지 작업복 외투로 상자 싸기**
  4. **신문 덮기**
- 순서가 틀리면 아이콘이 튕겨 나오며 일지 문장이 살짝 밝아진다.
- 일지 마지막 장 뒤 메모 → 수첩 자동 기록: **"피는 밤엔 셋. 바람 막고, 매트 22도, 불 끄고."**
- 해결: 상자가 포장되고, 하윤이 상자를 안아 든다. 성에가 잠시 물러나는 연출(타이머는 그대로).

### P8. 꽃이 멈췄다

- 전실로 돌아오면 월하미인이 반쯤 열리다 멈춰 있다. 셋 다 하면 해결, **순서 자유**.
- **① 바람 막기 (입김 재사용)**: 유리문 확대 → 입김 → 김이 한쪽으로 쏠리며 문틀 아래 왼쪽 틈이 드러난다. 소지품의 신문 뭉치를 틈으로 드래그. 마이크 없음/거부 → 유리문 길게 누르기.
- **② 매트 22도**: 눈금이 닳은 다이얼, 테이프 "보관 14 / 피는 밤 +8". 칸 단위로만 멈추는 다이얼을 **8칸** 더 돌린다. 매트 온도 스티커가 초록=22. 너무 돌리면 빨강.
- **③ 불 끄기**: 매트 보온등(빛)을 끈다. 열선은 유지.
  - 불부터 끄면 어두워서 다른 조작이 어렵다 → 휴대폰 불빛 아이콘이 생겨 손가락 주변만 밝아진다(엔진 어둠 + 손전등 마스크). 벌주지 않는다.
- 해결: 전실이 어두워지고, 정적 속에서 꽃이 열린다(만개 애니메이션 약 6초).

### 피날레. 네 차례

- 빈 이름표 옆 봉투 **"네 차례"**. 손가락으로 이름표에 직접 쓴다(1~8자, 비우면 진행 불가).
  - 쓰는 동안 화면 위쪽에 일곱 이름표가 비친다: 아 빠 봄 에 또 올 게.
  - 손글씨가 어려운 사람용 "글자로 쓰기" 버튼(엔진 한글 키패드, 크레용 글씨체로 표시).
- 상자와 월하미인을 안고 출입문으로 드래그 → 남 씨 → 엔딩 A.
- 퍼즐 수(8개)에 넣지 않는다.

## 6. 엔딩

- **A 「봄이네」**: 피날레 완료. 새벽 한결대병원 7층 병실. 화분 여덟 개, 맨 끝에 핀 월하미인과 하윤이 쓴 이름표. 아버지 "……봄이네." 결과 카드에 이름표 여덟 개.
- **B 「씨앗은 얼지 않는다」**: 시간 초과(0°C). 남 씨가 월하미인만 하윤 품에 안긴다. 병실에서 아버지 "…육묘실에. 네 상자. 씨는… 안 얼어." 『이듬해 3월』 하윤이 상자의 씨앗을 새 화분에 심고 크레용 이름표를 쓴다.
  - 반전 전(P6 이전)에 시간이 끝나도 같은 엔딩. 상자의 '존재'는 병실 대사로, '의미'는 마지막 장면에서 처음 드러난다.
- 오답(밸브, 학명, 번호, 스티커, 칸, 순서, 다이얼)은 엔딩이 아니라 피드백 후 계속.
- 결과 카드: 걸린 시간, 남은 온도, 힌트 사용 수("남 씨를 3번 불렀다"), 본 엔딩 도장. 엔딩 A는 이름표 여덟 장 이미지. 공유 이미지에는 크레용 일곱 글자를 흐리게, 플레이어 글자만 선명하게.

| 왼쪽 위          | 온도계(숫자 + 바늘) + 월하미인 봉오리 아이콘(탭하면 개화 정도 확대 보기) |
| 왼쪽 엄지        | 뒤로                                                                     |
| 오른쪽 위        | 수첩, 음소거, 설정, 최대 모드                                            |
| 오른쪽 세로      | 소지품 (칸 5개)                                                          |
| 오른쪽 아래 엄지 | 무전기(힌트)                                                             |

- 성에 오버레이: 남은 시간에 비례해 가장자리부터 번짐. 조작 영역(화면 중앙 80%)은 3°C 이하에서도 반투명 상한. "효과 줄이기" 설정이면 가장자리만.
- 노트 『육묘 기록』(P5·P6)은 화면 오른쪽 절반 시트로 열어 왼쪽 퍼즐과 나란히 본다.
- 일지(P7)는 펼친 공책 두 쪽, 세로 스크롤.
- 방 이동은 핫스팟 탭 → 확대(최대 2단계), "뒤로". 좌우 스와이프 이동 금지. 이 테마는 핀치 줌을 쓰지 않는다(확대는 탭으로).
- 설정(엔진 공통 + 이 테마): 입김 대신 길게 누르기, 성에 효과 줄이기.

## 10. 구현 메모 (공통 엔진 기준)

### 10-1. 테마 정의

```ts
gate:  { label: '문 열기', needs: ['mic'] }
timer: { skin: 'thermometer', durationMs: 30 * 60_000, onZero: 'B' }   // 14.0°C → 0.0°C 선형
hud:   { inventoryName: '소지품', hintChannel: 'radio', notebook: true }
extra: { bloomStage: 0, finaleStrokes: null, breathFallback: false }
```

### 10-2. 입김 (엔진 `BreathDetector`)

- P4 유리 확대 화면, P8 유리문 확대 화면에서만 판정을 켠다. 화면을 벗어나면 마이크 트랙을 바로 끈다.
- 넓은 대역 잡음 크기가 기준 이상으로 1.5초 쌓이면 성공.
- 대체 경로: 권한 거부·마이크 없음·판정 3회 실패 → 1.5초 길게 누르기. 3회 실패 시 「손으로 문질러 볼까.」 독백과 함께 자동 전환, `extra.breathFallback = true` 저장.
- 마이크를 끈 직후 오디오를 다시 깨운다(iPhone은 마이크 사용 중 출력 경로·음량이 바뀔 수 있음).

### 10-3. 월하미인 개화

- 5단계(봉오리 → 부풂 → 꽃잎 벌어짐 → 반개 → 만개). 게임 시간 5분마다 1단계, **반개에서 멈춤**. 만개는 P8 해결로만.
- 게임 시간 기준이므로 일시정지 구간에는 진행하지 않는다. `extra.bloomStage` 저장.

### 10-4. 온도계와 시간 보정

- 엔진 타이머 온도계 스킨. 14.0°C → 0.0°C, 30분 선형.
- P2 보상: `timer.pause(180000)`. 바늘 옆 불꽃 아이콘으로 표시.
- 경보 지점 7°C·3°C에 성에 단계 연출.
- P7 해결의 "성에가 물러나는" 연출은 그림만 바꾸고 타이머는 건드리지 않는다.

### 10-5. 화면 효과

- 성에: 엔진 `ScreenFilter` 성에 텍스처, 진행도 = 지난 시간 비율.
- P8 불 끄기 이후: 엔진 어둠 + 손전등 마스크(휴대폰 불빛 아이콘을 켰을 때만 구멍).
- 크레용 글자(P6): 이름표 위 글자 레이어 평소 투명도 8%, 생장등 점등 시 광택 그라데이션 + 70% (GSAP 2초, 왼쪽부터 한 글자씩).

### 10-6. 피날레 손가락 글씨

- PixiJS 그래픽으로 획을 그리고, 획 좌표를 `extra.finaleStrokes`에 저장(새로고침해도 유지).
- 결과 카드는 PixiJS 화면을 이미지로 뽑아 이름표 여덟 장을 합성.
- "글자로 쓰기" 대체: 엔진 한글 키패드, 1~8자, 크레용 글씨체로 렌더.

### 10-7. 사운드

- 소리 단서 없음 → iPhone 무음 스위치로 꺼져도 진행 가능.
- 배경: 바람·보일러·온풍기 루프. P7 진입과 P8 해결은 배경음을 완전히 끊는다(정적이 연출).
- 회상 음성(P6)은 음성 볼륨 채널. 자막 필수.

### 10-8. 저장

- 저장 키 `escape:neulbom-greenhouse`. v2(Unity) 저장과는 호환하지 않는다(새 출시).
