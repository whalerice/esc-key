# ESC KEY Playtest & QA Balancing Skill

## Overview

기준 문서: `docs/개발/공통엔진_v1.md`. 힌트·정체·일시정지·실기기 판정은 그 문서가 이긴다.

난이도 밸런스, 3단계 힌트, 정체 감지, 출시 전 QA.

## 1. 3-Tier Progressive Hint System (3단계 힌트 표준)

플레이어의 몰입을 깨지 않으면서 막힘(Frustration)을 해소하기 위해, 모든 퍼즐은 반드시 **3단계 힌트**를 정의해야 합니다.

| 단계 | 명칭 | 역할 및 내용 | 예시 (새말역 P3: 천지인 문자) |
| :---: | :---: | :--- | :--- |
| **1단계** | **방향 제시 (Direction)** | 플레이어가 무엇을 보아야 하는지 시선 유도 (생각할 계기 마련) | *"옛날 피처폰은 숫자 키패드에 한글 자음과 모음이 같이 적혀 있었지."* |
| **2단계** | **구체 단서 (Detail)** | 풀이 공식과 규칙을 직접 설명 (사고 과정 보조) | *"사용 안내 카드 표를 봐. 8은 'ㅅ'이고, 21은 모음 'ㅓ' 하나다."* |
| **3단계** | **정답 공개 (Answer)** | 완전 정체 시 탈출을 이어갈 수 있도록 최종 정답 제시 | *"정답: '선물 눈사람'을 수첩 해독 칸에 입력해라."* |

### 오조작 방지 규칙
- 힌트 단계 열기는 **길게 누르기 기본 600ms** (`gestures.ts`, 값 조절 가능). 탭 한 번으로 열지 않는다.
- 1.5초 길게 누르기는 힌트가 아니다. 겨울 온실 입김 실패·권한 거부 대체만 1.5초다.

## 2. Stagnation Detection (플레이어 정체 감지)

플레이어가 한 퍼즐에서 진전을 보이지 못하고 헤매는 시간을 자동으로 추적하여 적절한 도움을 제공합니다.

- **감지 기준**:
  - **30분 테마**: 한 퍼즐에서 **3분** 동안 유효한 상호작용(새 단서 열람, 정답 시도 등)이 없을 때.
  - **60분 테마**: 한 퍼즐에서 **5분** 동안 정체될 때.
- **개입 연출 (In-Game Nudge)**:
  - 힌트 아이콘(예: 카운터 내선 전화기 램프, 수첩 아이콘)이 은은하게 깜빡이거나 벨이 울림.
  - 몰입을 깨는 시스템 팝업 대신 인물 간 내러티브 연출(예: 곽 반장의 내선 전화 "지훈아, 아직 충전기 못 찾았냐?") 활용.

## 3. Playtest Metrics & Balancing Criteria (밸런싱 평가 지표)

QA 플레이테스트 시 아래 지표를 측정하여 난이도를 튜닝합니다.

1. **테마 목표 클리어 타임 편차**:
   - 30분 테마: 평균 플레이 시간 **26분 ~ 32분** 이내 수렴.
   - 60분 테마: 평균 플레이 시간 **50분 ~ 58분** 이내 수렴.
2. **퍼즐별 이탈/정체율 (Choke Point)**:
   - 특정 퍼즐에서 전체 플레이어의 40% 이상이 힌트 3단계를 보거나 제한시간의 30% 이상을 소모한다면 즉시 난이도 하향 조정.
3. **오답 패턴 로깅 (False Answer Analysis)**:
   - 플레이어가 '합리적'이라고 생각했으나 기획자가 고려하지 못한 오답이 빈번할 경우, 해당 답안도 정답으로 인정하거나 혼선을 주는 단서를 제거.

## 4. End-to-End QA Checklist (출시 전 검증)

- [ ] **논리적 무결성**: 단서를 보지 않고는 풀 수 없으며, 단서를 조합했을 때 정답이 유일무이(Unique)한가?
- [ ] **3단계 힌트 완비**: 모든 퍼즐에 1단계(방향), 2단계(구체 단서), 3단계(정답)가 빠짐없이 등록되었는가?
- [ ] **터치**: 높이 360px 기준 핫스팟 44×44px. 좌우 24px·아래 20px 금지 띠에 단서가 없는가?
- [ ] **저장**: 퍼즐 해결·아이템 획득·백그라운드 진입 후 이어하기. 키 `escape:<themeId>`.
- [ ] **시간**: 세로·백그라운드·시스템 오버레이 동안 남은 시간이 멈추는가. 전체화면 해제·모달·엎어두기 중 회전에서는 멈추지 않는가. 타이머 없는 테마(1/12)는 시간 초과 엔딩을 강요하지 않는다. `onZero`가 있는 테마만 그 엔딩으로 간다.
- [ ] **힌트 롱프레스**: 기본 600ms. 실수 탭으로 단계가 열리지 않는가?
- [ ] **실기기**: 공통엔진 §18. Android 전체화면+가로 잠금, 뒤로가기 해제 후 게임 계속·최대 모드 깜빡임, iPhone Safari `100dvh`와 홈 화면 추가 1회, 홈 화면 실행 시 주소창 없음, 무음 스위치 소리 단서 또는 시각 대체, 마이크·기울기 거부 후 완주, 엎어두기 중 회전 안내 없음, 저사양 30fps.
